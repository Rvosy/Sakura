应用打开遇到问题？

如果 macOS 提示无法验证开发者，请只在确认 Sakura 来自官方 Release 后继续。

下面的 Apple 官方流程只为 Sakura 保存本机例外，不会关闭系统的安全检查。

  1. 1
    先尝试打开一次 Sakura

    尝试后，“仍要打开”按钮才会出现，并保留约一小时。

  2. 2
    打开“系统设置”

    在侧栏选择“隐私与安全性”，然后向下找到“安全性”。

  3. 3
    点击“仍要打开”

    确认显示的应用是 Sakura，再继续。

  4. 4
    完成身份验证

    输入 Mac 登录密码，并再次确认打开。

旧版本迁移

选择旧版 Sakura 的根目录。迁移只读取旧目录，完成前不会改动现有数据。
