# 角色和数据迁移预览

本页面直接复用正式设置页的 `legacy-data-import.js`、主题样式和自定义下拉菜单，仅将目录选择与后端接口替换成内存演示数据。不会读取或修改真实用户目录。

在仓库根目录运行 `runtime\python.exe -m http.server 8771 --bind 127.0.0.1 --directory desktop/frontend`，打开 <http://127.0.0.1:8771/prototypes/legacy-data-import/>。

点击“迁移旧数据”，再选目录。可以切换普通数据、冲突、全部重复、无数据、错误目录和坏数据场景；N.A.V.I. 演示同名角色的显式关联。角色选择、冲突确认、迁移中锁定与完成状态运行正式前端逻辑。

生产入口在设置 → 系统。后端导入角色包、聊天记录和记忆，共用角色身份映射与事务。包无法加载或记录损坏时尽量保留可用数据，不计算哈希，也不以扫描快照变化拒绝整批迁移。详细行为见[迁移 Spec](../../../../docs/specs/runtime-v2/legacy-0.9-import.md)。
