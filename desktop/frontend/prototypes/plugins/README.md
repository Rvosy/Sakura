# 插件页体验原型

独立的前端外观原型，供后续正式页面改造参考。插件状态、设置和操作使用演示数据，只保存在页面内存中。

本次只确定页面外观。设置字段、默认值、校验、保存与动作行为以现有插件声明和调用链为准，不根据 demo 新增功能。
唯一明确的入口迁移是：将 GPT-SoVITS 与 Genie 整合包下载从“关于”放进各自的插件设置窗口。
正式应用尚未接入本原型。

在仓库根目录启动静态服务：

```powershell
.\runtime\python.exe -m http.server 8767 --bind 127.0.0.1 --directory desktop/frontend
```

打开 http://127.0.0.1:8767/prototypes/plugins/ 。也可以直接打开本目录的 `index.html`；页面没有构建步骤或远程依赖。

顶部可切换 5、9、30 个插件的场景。“规划示例”和“生态示例”用于检验扩展后的布局，不表示 Sakura 已实现这些插件。

- 用角色分类和领域、来源、状态组合筛选；按 `/` 聚焦搜索。
- 系统组件默认收起，入口固定在列表底部；搜索或筛选命中时展开。
- 每个插件使用独立卡片；选中项显示蓝色边框与浅蓝底色，不显示左侧色带。
- 详情标题右侧是紧凑的“插件设置”按钮，运行状态放在按钮下方；异常原因在介绍之后单独显示。
- 设置窗口支持现有字段的分组、高级折叠区、只读状态和条件禁用。已有服务字段始终可见，在选择“连接已有服务”后可编辑。
- Genie 的“本地运行组件”示例已安装；GPT-SoVITS 可模拟下载、取消和重试。关闭窗口后模拟任务继续；保存已有服务模式后，重新打开显示无需安装。
- 安装、卸载、启停与状态刷新均为模拟操作；刷新页面或“重置演示”恢复数据。

## 设置样例来源

`data.js` 中的普通设置字段逐项对应以下声明。字段名称、类型、默认值、边界与条件来自源码；分组宽度等只用于排版。

| 插件 | 现有设置 | 声明来源 |
|---|---|---|
| GPT-SoVITS | 服务来源、已有服务地址、接口路径、远程参考音频目录、内置服务工作目录、Python 解释器、推理配置、合成超时 | [plugin.py](../../../../plugins/builtin/sakura_gpt_sovits/plugin.py) |
| Genie | 服务来源、已有服务地址、合成超时 | [plugin.py](../../../../plugins/builtin/sakura_genie/plugin.py) |
| Sakura Mobile | 启用手机网页端、监听地址、端口、访问 token、只读运行状态与地址、错误、刷新状态 | [plugin.py](../../../../plugins/builtin/sakura_mobile/plugin.py) |
| Mem0 | 运行状态、自动整理间隔 | [plugin.py](../../../../plugins/builtin/sakura_mem0/plugin.py) |
| Playwright Browser | 无头模式 | [plugin.py](../../../../plugins/optional/playwright_browser/plugin.py) |

GPT-SoVITS、Genie 不增加音色、输出语言、语速、参考音频选择、分段或流式开关。Mem0 的向量模型下载和记忆内容管理保留现有入口。
模型规划示例、生态样例和模拟安装的 Notebook Companion 没有真实设置声明依据，因此不提供虚构表单。

## 原型实现

`data.js` 定义场景与设置样例，`app.js` 负责交互，`controls.js` 处理自定义下拉框和弹窗退出。
`styles.css` 沿用 Sakura 的主题色与本地字体。此目录不接入 Tauri 或插件运行时，也不读取用户数据。

下拉框参考正式设置页的 `enhanceSelect`：保留原生字段承载值与 change 事件，使用可主题化的列表弹层，支持方向键、Home/End、Enter、Esc 和 Tab。
弹层在设置对话框中不会被滚动区域裁剪。动效沿用 `settings/styles.css` 的缓动曲线、时长与位移，覆盖按钮、开关、详情切换、菜单、弹窗和提示消息，并遵循系统减少动态效果设置。

`settingsPage: { title, description, sections }` 只组织本页样例，不是新的 Manifest 或 SDK 契约。
模拟保存按插件保留值；取消、关闭或 Esc 放弃本次编辑。模拟下载独立于表单草稿，只根据已保存的服务来源展示适用状态。
资源进度、插件运行状态使用独立样例，不互相推导。这些交互便于查看外观，不定义正式产品的保存时机、任务生命周期或业务规则；接入时继续使用原有链路。
