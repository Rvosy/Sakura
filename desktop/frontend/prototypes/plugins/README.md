# 插件页体验原型

独立的前端布局原型。所有插件状态、设置和安装操作均使用演示数据，只保存在页面内存中。

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory desktop/frontend
```

打开 http://127.0.0.1:8767/prototypes/plugins/ 。也可以直接用浏览器打开本目录的 `index.html`；页面没有构建步骤或远程依赖。

顶部可切换 5、9、30 个插件的场景。“规划示例”和“生态示例”用于检验扩展后的布局，不表示 Sakura 已实现这些插件。

- 用角色分类和领域、来源、状态组合筛选；按 `/` 聚焦搜索。
- 系统组件默认收起，入口固定在列表底部；搜索或筛选命中时展开。
- 从依赖项跳转到对应插件，试用停用影响提示。
- 点击“插件设置”，在弹出窗口中编辑插件自己的设置。Genie、GPT-SoVITS、Mobile、Playwright 等使用同一窗口；未声明设置页的插件不显示入口。
- 安装、卸载与启停均为模拟操作；刷新或“重置演示”恢复数据。

`data.js` 定义场景与插件样例，`app.js` 负责交互，`styles.css` 沿用 Sakura 的主题色与本地字体。此目录不接入 Tauri 或插件运行时，也不读取用户数据。

插件样例通过 `settingsPage: { title, description, sections }` 声明设置页。每个分组声明标题和字段，可包含文本、多行文本、密码、数字、下拉选项、滑块、复选框以及条件显示。分组可设为高级折叠区。渲染器只读取这份声明，不按插件 ID、角色或领域选择表单。这里的声明仅用于原型，不是正式 SDK 契约。

保存按插件分别保留页面内存中的值；取消、关闭或按 Esc 放弃本次编辑。修改配置不会改变模拟运行状态。正常运行状态放在插件名称下方，异常原因在介绍之后单独显示。
