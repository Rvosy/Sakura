# 输入栏状态原型

只展示当前桌宠形态：N.A.V.I. 默认立绘与输入栏。用于讨论语音输入的前端表现。

直接引入正式前端的 `../../styles.css`，复用输入栏、字体、图标、立绘与附件样式；原型样式只补充麦克风、波形及页面承载区域。初始主题与位置取自本次本地配置快照：粉色主题、毛玻璃输入栏、宽度 553、纵向偏移 -26、立绘比例 100%。原型不读取或修改运行中的配置。

点击麦克风后短暂准备，再显示缓慢移动的模拟波形，不显示录音计时与上限。停止按钮使用浅灰底色和深色小方块，保留原有点击区域。左侧扩展按钮复用同一个元素：语音输入时从「＋」在 160 毫秒内旋转 225° 成「×」，用于取消；完成或取消后转回「＋」，恢复扩展功能。再次点击停止，短暂显示识别状态，随后在草稿中插入固定文字。Esc 同样可以取消。发送仅清空输入并短暂提示，不调用后端。

右下角“状态预览”默认收起，展开后可固定查看准备、录音、识别、回填、无声、失败、不可用等状态，也可查看安静波形和切换承载背景。此面板只是评审辅助，不属于产品界面。

准备与识别期间，输入栏保持单行高度，在整条输入栏中央显示「正在准备」或「正在识别」，右侧保留加载指示。此时暂时隐藏草稿和附件，不显示输入栏外的识别提示；完成或取消后恢复原内容。

在仓库根目录运行：

```powershell
runtime/python.exe -m http.server 8766 --bind 127.0.0.1 --directory desktop/frontend
```

打开 <http://127.0.0.1:8766/prototypes/asr/>。无依赖安装、构建或后端要求；HTML 本身也可直接打开。

立绘 `assets/navi.png` 是现有 `characters/N.A.V.I/portraits/A010.png` 的原样副本，仅供本地评审。浏览器的毛玻璃只能模糊网页内容，不能模拟宿主对真实桌面的系统模糊。正式应用文件和角色资源均未改动。
