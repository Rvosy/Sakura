# 联网搜索与网页读取

Sakura 自带“联网工具”插件，新安装默认启用。它可以搜索公开网页、读取链接内容，不需要配置 MCP。是否搜索、使用哪些关键词以及是否继续读取网页，由聊天模型根据对话决定。

在“设置 → 插件”选择“联网工具”，可以启用、停用或打开“插件设置”。查询服务支持百度、Bing 和 Tavily，默认使用百度。百度和 Bing 无需 API Key；选择 Tavily 后，需要填写 Tavily API Key，并可选择 Basic 或 Advanced 搜索深度。填写测试关键词后，点击“测试搜索”检查连接。

搜索返回标题、链接和摘要。网页读取返回文本，过长内容会截断；选择 Tavily 时通过其正文提取服务读取，其他服务直接提取网页文本。不支持登录后的内容或需要浏览器执行脚本才能显示的页面。需要打开、点击或填写网页时，使用独立的浏览器插件。

停用“联网工具”后，模型不再能调用它提供的搜索和读取工具，其他插件和模型服务仍按各自配置联网。升级会保留原先的停用选择；没有自动开启时，可到插件页检查。

请求超时、网站拒绝访问或搜索页面无法解析时，会显示具体原因。插件运行正常只表示工具可调用，不保证每个网站都能访问。更多信息见[运行日志](RUNTIME_LOG_TROUBLESHOOTING.md)。
