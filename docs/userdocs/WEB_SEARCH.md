# 联网搜索与网页读取

Sakura 自带“联网工具”插件，可以搜索公开网页、读取链接内容。新安装默认开启，无需配置 MCP、搜索服务或
API Key。是否搜索、使用哪些关键词以及是否继续读取网页，由聊天模型根据对话决定。

在插件页选择“联网工具”可以启用或停用。插件没有自定义设置；停用后模型不再获得这两个工具，其他插件和
模型服务仍按各自配置联网。升级会保留旧的关闭选择，未自动开启时可到插件页检查。

搜索使用 Bing，返回标题、链接和摘要。网页读取返回文本，过长内容会截断；不支持登录后的内容或需要
浏览器执行脚本才能显示的页面。需要打开、点击或填写网页时，使用独立的浏览器插件。

请求超时、网站拒绝访问或搜索页面无法解析时，会返回具体失败原因。插件显示运行正常只表示工具可调用，
不保证每个网站都能访问。旧配置无法迁移时，查看[运行日志](RUNTIME_LOG_TROUBLESHOOTING.md)中的
`WEB_MIGRATION_*` 原因，修正旧 MCP 配置后重新启动。
