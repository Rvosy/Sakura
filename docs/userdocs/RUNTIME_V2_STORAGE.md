# 数据与存储

Windows 安装版和 Portable 把配置、角色、聊天数据和 TTS 保存在 Sakura 目录中。macOS 将这些内容保存在：

```text
~/Library/Application Support/Sakura
```

Linux 正式版默认使用 `${XDG_DATA_HOME:-$HOME/.local/share}/Sakura`，源码开发版使用同一位置下的 `Sakura Development`。

可以在“设置 → 系统 → 用户数据”查看并打开数据目录。macOS 更新会替换 `.app`，不会删除 Application Support
中的内容。

TTS 资源默认位于数据目录下的 `tts`，也可以在设置中选择已经存在且可写的外置硬盘目录。更改位置不会自动移动旧文件。

外置盘断开时，Sakura 不会改用默认目录。文字聊天和设置仍可使用，TTS 会显示存储不可用。

## 更新

Windows Setup 与 macOS 安装版支持应用内更新，安装前会验证更新包签名。安装器替换发行资源并保留用户数据；升级后的首次启动可能执行插件或配置兼容迁移，见[插件升级说明](RUNTIME_V2_PLUGINS.md#升级已有安装)。Windows Portable 不自替换，也不会启动 NSIS；发现新版本后，需要下载新版 Portable ZIP，退出 Sakura，再解压到目标目录。

Sakura 正常启动不会自动扫描旧目录。Windows 用户首次设置尚未完成且新版数据为空时，可以通过“迁移旧版本”选择 0.9.x 目录，完成离线转换和校验。

已经开始使用新版的用户，可从“设置 → 系统 → 用户数据 → 迁移旧数据”导入角色包、聊天记录和记忆。先退出旧版，再选择目录，核对角色关联及新增、重复、冲突记录；存在冲突时需要确认覆盖。当前环境不支持时，入口会置灰。不要直接用旧 `data/` 覆盖新版数据。

`tools/cleanup.py` 默认只预览可清理内容。确认列表后才使用 `--apply`。不要对不确定的目录执行清理。

## 从 1.1.0 升级

旧角色包和聊天历史继续可用。原来的立绘会显示为“立绘1”，在“设置 → 角色与布局”的“显示方式”中选择。
立绘需要“立绘”插件保持启用；增加其他形态需要安装对应插件，并准备该形态的资源。
角色工坊会恢复升级前尚未保存到角色的草稿，包括修改过的默认图片和表情标签。

升级时会把本机已有角色的旧语音开关和引擎选择补入本机配置，已经设置过的新选择不会被覆盖，原本关闭的
语音也不会被打开。模型、参考音频和引擎配置仍保留，无需重新导入；已停用的引擎插件仍保持停用。

新版支持导入旧版 `.char` 角色包，保留立绘、人设和语音资源。新导入角色不继承包内的语音开关和引擎选择，
请在本机语音设置中选择引擎并启用。新的语音选择只保存在本机，分享角色包不会带走这些选择。

旧 MCP 配置不再恢复；联网工具通过插件页管理。
