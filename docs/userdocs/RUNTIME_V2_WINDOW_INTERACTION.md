# 窗口交互

Sakura 的桌宠窗口只在立绘和可见控件上接收鼠标。立绘透明像素、控件外区域和收起后的空白会把点击交给下面的窗口。

## 鼠标行为

- 在立绘或对话框空白处拖动，可以移动桌宠。
- 回复文字、输入框、按钮、菜单和滚动条保留正常交互。
- 右键立绘打开桌宠菜单。
- 表情切换时，命中范围暂时覆盖新旧立绘的可见区域，动画结束后再收紧。

窗口位置以立绘底部中心为锚点。首次显示时 Sakura 会把可见区域放进当前工作区；之后由用户拖动的位置优先，多显示器上的负坐标也会保留。

## 调整布局

拖动立绘倍率或布局滑块时，前端先更新画面，原生窗口在手势开始和结束时处理必要的包络变化。这样可以避免桌宠在连续拖动中反复跳动。松开鼠标、取消手势或设置窗口失去焦点后，命中范围会按最终值收紧。

Windows、macOS 和 Linux 使用各自的原生输入区域接口。Wayland 是否允许应用绝对定位取决于桌面环境；无法定位时，缩放和点击穿透仍可工作，但桌面环境可能决定最终位置。

## 排查

- 整个透明窗口都挡住点击：重启 Sakura，确认系统合成器没有禁用透明窗口能力。
- 立绘无法拖动：从不透明区域开始拖动；全透明角色只能从对话框等可见控件移动。
- 高 DPI 或多屏幕下命中偏移：记录显示器排列和缩放比例，再查看运行日志中的窗口诊断。
- 调整倍率后短暂错位：等待手势结束；若最终仍错位，重新打开设置并保存一次。

报告问题时请附系统版本、桌面环境、显示器排列、每块屏幕的缩放比例和可复现的操作顺序。
