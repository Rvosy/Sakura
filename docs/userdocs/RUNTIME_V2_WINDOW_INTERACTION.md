# 窗口与外观

Sakura 的桌宠窗口只在立绘和可见控件上接收鼠标。立绘透明像素、控件外区域和收起后的空白会把点击交给下面的窗口。Linux 上原生点击穿透使用立绘可见范围的外接矩形，发丝等镂空处仍可能挡住下方窗口。

## 鼠标行为

- 在立绘或对话框空白处拖动，可以移动桌宠。
- 回复文字、输入框、按钮、菜单和滚动条保留正常交互。
- 右键立绘打开桌宠菜单。
- 表情切换时，可接收鼠标的区域暂时覆盖新旧立绘的可见部分，动画结束后再收紧。

窗口位置以立绘底部中心为位置基准。首次显示时 Sakura 会把可见区域放进当前工作区；之后由用户拖动的位置优先，多显示器上的负坐标也会保留。

## 调整布局

拖动立绘倍率或布局滑块时，画面会立即更新。窗口只在开始和结束调整时改变必要的范围，避免桌宠在连续拖动中反复跳动。松开鼠标、取消调整或设置窗口失去焦点后，可接收鼠标的区域会按最终布局收紧。

Windows、macOS 和 Linux 使用各自的原生输入区域接口。Linux 的点击穿透使用立绘可见区域的外接矩形，不把 PNG 发丝镂空交给 GTK/XShape。Wayland 是否允许应用绝对定位取决于桌面环境；无法定位时，缩放和点击穿透仍可工作，但桌面环境可能决定最终位置。

## 外观与背景效果

“设置 → 角色与布局”控制立绘、对话框和输入栏的位置与尺寸。“设置 → 外观”控制颜色和输入栏背景效果。拖动滑块时，桌宠会立即预览；保存后写入当前角色的配置。

可调项目包括立绘大小、对话框宽高、气泡和输入栏位置、字体大小、主题色及背景效果。对话框使用固定外框高度，长回复在框内滚动，不会推着整个桌宠上下移动。

输入栏效果按平台提供：

- Windows 支持纯色及系统条件允许时的实时高斯模糊；液态玻璃暂未实现，选项会置灰；
- macOS 支持纯色、高斯模糊、原生材质，系统支持时还可选择原生 Liquid Glass；
- Linux 使用纯色或 GTK/桌面环境能够提供的效果。

平台不支持的选项会置灰。已经保存的其他平台偏好会留在配置里，但当前平台只应用自己支持的效果。
Windows 的高斯模糊可能因系统版本、透明效果、节能策略或图形能力而不可用，此时会改用纯色。桌宠会提示从右键菜单打开“运行日志”查看原因。

预览失败时，Sakura 会恢复上一份可用设置。若界面与保存值不一致，先关闭设置窗口再打开；仍未恢复时重启 Sakura，并查看[运行日志](RUNTIME_LOG_TROUBLESHOOTING.md)。

## 排查

- 整个透明窗口都挡住点击：重启 Sakura，确认系统合成器没有禁用透明窗口能力。
- 立绘无法拖动：从不透明区域开始拖动；全透明角色只能从对话框等可见控件移动。
- 高 DPI 或多屏幕下鼠标响应位置偏移：记录显示器排列和缩放比例，再查看运行日志中的窗口诊断。
- 调整倍率后短暂错位：等待手势结束；若最终仍错位，重新打开设置并保存一次。

报告问题时请附系统版本、桌面环境、显示器排列、每块屏幕的缩放比例和可复现的操作顺序。
