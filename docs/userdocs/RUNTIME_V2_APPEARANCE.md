# Runtime v2 外观与输入栏效果

在“设置 → 外观 → 输入栏 → 外观效果”可以选择：

- **高斯模糊**：Windows 11 或 macOS 13 及以上实时模糊桌宠窗口后方的桌面内容；这是缺省选项。
- **液态玻璃**：Windows 11 上在实时背景之上加入连续折射、色散、Fresnel 亮边与 glare；这是需要
  单独选择的实验效果。当前安全候选因系统截图隔离限制会停止桌面捕获并显示受限的液态外观；它不会
  偷换成高斯模糊，也不会隐藏系统截图中的桌宠。设置偏好保持为液态玻璃。
- **纯色块**：使用 Runtime v2 的不透明输入栏。

macOS 26 及以上使用系统 `NSGlassEffectView` 提供原生液态玻璃；macOS 13–15 的高斯仍可使用，但液态
选项会置灰并提示“需要 macOS 26 或更高版本”。若在另一平台已经保存液态偏好，旧 macOS 会保留该
偏好并显示纯色，不会用高斯冒充液态效果。macOS 输入栏会同时模糊桌面和位于输入栏下方的角色立绘。

选择会立即预览；取消设置会恢复打开页面时的效果，保存后重启仍会保留。该选项是全局偏好，不会随
角色主题切换。Linux 当前不支持实时桌面高斯或液态玻璃；在不支持的系统保存其他外观设置不会清除
已经保存的效果偏好。

如果 Windows 或 macOS 原生玻璃整体初始化失败，Sakura 会自动显示纯色输入栏，聊天、拖动和退出仍可
使用。若只有液态后端受限、熔断或系统版本不足，则关闭高斯替代层。所有情况都不会更改已保存的偏好。
