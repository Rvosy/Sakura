# Runtime v2 外观与输入栏效果

在“设置 → 外观 → 输入栏 → 外观效果”可以选择：

- **高斯模糊**：Windows 11 上实时模糊桌宠窗口后方的桌面内容；这是缺省选项。
- **纯色块**：使用 Runtime v2 的不透明输入栏。

选择会立即预览；取消设置会恢复打开页面时的效果，保存后重启仍会保留。该选项是全局偏好，不会随
角色主题切换。macOS 与 Linux 当前不支持实时桌面高斯，控件会显示“实时桌面高斯仅支持 Windows”；
在这些平台保存其他外观设置不会清除已经保存的高斯偏好。

如果 Windows 原生效果初始化失败，Sakura 会自动显示纯色输入栏，聊天、拖动和退出仍可使用。此降级
不会更改已保存的偏好；重启后会再次尝试初始化。
