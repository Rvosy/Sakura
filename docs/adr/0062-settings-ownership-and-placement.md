# ADR-0062：配置归属与设置页面展示分离

## 背景

功能迁移到插件后，连接配置被改成通用集合编辑，语音控件也曾借到插件设置窗口。配置归属改变带动了界面布局和保存时机变化，
用户原来的操作流程因此被打断。插件化需要开放设置扩展能力，同时保留宿主已有的功能页面。

## 决策

插件持有配置、作用范围和业务回调，宿主持有页面框架、组件、导航与窗口草稿。设置按使用流程归位：日常功能放在功能页，
深度参数留在功能页高级设置，运行环境与维护参数放在插件设置，启停、版本、依赖和卸载留在管理详情。
API 地址和密钥仍在模型服务页。

沿现有 Settings 注册增加命名空间页面、区块放置和宿主组件组合，不增加第二套存储或保存接口。页面支持明确开放的区域，
插件只能管理自己的贡献；相同标题和局部 ID 不冲突。侧栏维持原四组和原页面顺序，新页面追加到对应组。
旧 surface-v0 映射仍可显示，语音和记忆保留原布局。插件退出由既有 scope 清理贡献。

每个区块只有一个主要编辑位置。插件详情独立提供功能页跳转；只有存在底层设置时显示“插件设置”。
私有弹窗“完成”接受草稿，外层“应用”“保存并关闭”提交；发现模型和测试连接使用当前草稿，不提前保存。
下载、诊断、记忆记录管理等动作保留自己的执行时机，取消设置不能撤销已经执行的动作。
部分写入成功或应用失败必须报告实际结果，未完成的编辑仍可继续处理。

## 取舍

复用宿主组件限制了插件视觉自由，但能保持导航、主题、字段和弹窗体验一致。首期支持普通表单、折叠分组、列表详情、
模型选择、连接编辑、状态和动作；连接编辑包含发现勾选与手动添加。增加组件应由实际功能驱动，不开放任意 HTML、JavaScript 或 CSS。
模型提供方、Assistant 和主动屏幕感知通过相同公开接口接入，不根据内置插件名称分支。

本决策细化 [ADR-0061](0061-model-providers-and-plugin-interactions.md) 的配置边界，不改变模型服务生命周期或主动屏幕感知策略。
公共接口见 [SDK](../devdocs/SAKURA_PLUGIN_SDK.md#页面与区块贡献) 与 [Runtime Spec](../specs/runtime-v2/sakura-plugin-runtime-v4.md)。
