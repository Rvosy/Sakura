# ADR-0050：当前角色编辑局部更新，角色切换保留 generation 隔离

工坊过去为了替换整个角色目录，先关闭聊天、语音和所有插件，再重启 Core。修改形态名称或提示词也会重新启动与改动无关的服务；发布失败后还需要重建已经关闭的会话。

当前角色发布改为逐文件事务：比较实际内容，只暂存和替换变化文件，保留旧包完整备份及恢复 journal。未修改的模型文件保持原位，普通编辑不必释放其读取者。进程中断时按变化文件列表回滚；旧版目录事务仍可恢复。此选择接受文件替换期间短暂的新旧资源并存，不承诺对任意外部读取者提供整个目录的原子视图。

保存与运行态更新分开。表现立即重新绑定；提示词、名称和回复语气在既有聊天请求边界更新，不替换 Assistant Session。语音资源变化时，只暂停活动语音服务及其硬依赖方，发布或回滚后按依赖顺序恢复。暂停不改变插件的启用配置，恢复失败单独报告，不把已保存的数据说成保存失败。

角色 ID 变化和首次建立角色会话继续使用受控 Core 重启，保留聊天历史、记忆、异步回调的 generation 隔离。本决策取代角色工坊与语音包导入中“同角色修改必须重启”的行为，不改变跨角色切换契约。细节见[角色工坊](../specs/runtime-v2/character-studio.md)与[安全角色切换](../specs/runtime-v2/WP-5-03-safe-character-switch.md)。
