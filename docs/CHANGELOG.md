# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.2

新增 SakuraTTS 语音引擎接入，改进插件设置、错误诊断和运行日志，并修复角色显示与工作室交互问题。

- SakuraTTS 作为内置插件随应用分发并默认启用，支持本地整合包导入、在线下载和检查更新，沿用角色模型与参考音频配置，支持空闲休眠、对话开始时提前唤醒和 NVIDIA 推理精度选择。
- 修复插件设置和语音引擎状态刷新，保留设置弹窗中的未保存内容。
- 升级已安装的官方插件时保留配置、资源和启停状态，手机聊天插件统一为 1.1.0 正式版。
- 错误弹窗支持展开和复制完整诊断，保留模型、语音及插件调用失败的具体原因。
- 运行日志区分执行过程、进度与结果，补充主动看屏幕的状态和语音合成耗时。
- 修复角色切换后的配色读取、缩放回弹，以及角色工作室选单在滚动时关闭的问题。
- 统一界面用语和状态提示，修正记忆召回字段的处理。
