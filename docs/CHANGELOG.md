# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.5

改善 Windows 升级时的目录选择，修复从旧目录导入数据时的部分失败。

- **从 1.3.3／1.3.4 升级**：Windows 安装器会显示目录选择页。请选择原来的 Sakura 目录，以继续使用已有角色、插件和设置。如果之前已经安装到了另一个目录，本次更新不会自动合并两处数据，可从旧目录导入。
- **后续自动更新**：安装 1.3.5 后，再次自动更新时会沿用当前程序目录，避免因安装记录指向其他位置而换到新目录。
- **导入旧数据**：历史插件备份目录无法读取时，不再因此中断导入；修复部分长期记忆数据读取失败后，因文件仍被占用而导致导入预览无法完成的问题。
- **长期记忆插件需单独更新**：Mem0 0.2.1 支持在尚未选择角色时安装、启用，并提示先选择角色；选择或切换角色后使用对应的记忆库。此修复需要单独更新 Mem0，升级主程序不会替换已安装的插件。
