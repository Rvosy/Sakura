# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.6

新增聊天记录导入导出，修复旧数据迁移、插件升级和部分模型调用失败的问题。

- **导入导出聊天记录**：聊天记录窗口新增导入、导出入口。Sakura JSON 用于迁移和恢复，TXT 用于查看和分享；聊天记录可按日期范围导出。导入前可预览新增、重复和冲突数量，重复记录跳过，冲突保留本地内容。支持从其他角色复制数据，具体用法见[数据、备份与迁移](guide/data.md#导入导出聊天记录)。
- **修复旧数据迁移**：修复对应插件已安装，但导入旧版长期记忆或语音配置时仍提示缺少依赖的问题。
- **修复模型兼容问题**：部分模型只接受默认温度参数，现在可自动使用模型默认值继续请求，避免因此导致聊天或记忆整理失败。
- **修复记忆加载状态**：停用或重新加载 Mem0 后，之前的加载任务不再覆盖当前状态或显示过期错误。
- **处理插件重复安装**：升级后忽略已外置插件的旧内置副本，保留原有配置和数据，避免重复入口及旧副本阻挡用户版启动、更新。其他重复安装会显示处理提示，方便按版本和目录选择保留的副本。
- **修复插件更新与恢复**：插件文件损坏或更新中断后，可从市场或本地包重新安装修复，保留启停选择和业务数据。启动失败时显示具体原因，可修改配置或重新安装；旧配置中的无效条目不再阻挡其他插件。
- **减少插件更新时的等待**：准备安装依赖期间，可以继续保存其他插件的设置，也可以停用或卸载正在更新的插件，更新会尊重这些操作。
- **保留其他插件副本的使用状态**：卸载重复副本时，保留其他副本仍在使用的依赖和启停选择。
- **更新默认下载源**：替换失效的 GitHub 下载镜像，涉及插件市场、语音识别资源及 macOS GPT-SoVITS 安装。
