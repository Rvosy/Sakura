# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.6

修复旧版本升级后出现两份长期记忆插件、旧副本阻挡用户版启动和更新的问题。

- **处理升级残留**：启动时忽略已外置插件的旧内置副本，使用已安装的用户版。已经出现重复入口的安装也适用，保留原有配置和数据；缺少用户版时可从市场或本地包安装。
- **修复已有安装**：市场、ZIP 和文件夹共用更新流程。插件清单损坏、入口代码缺失或更新中断后，可以重新安装完整插件包修复，保留启停选择和业务数据。损坏的更新记录与备份会保留，旧文件清理失败不阻断已经完成的更新。
- **保留恢复入口**：插件启动失败时保留已安装的新版本和具体错误，可继续修改配置或重新安装；旧配置中的无效条目不再阻断其他有效条目。
- **补全处理日志**：记录忽略旧副本、安装准备、版本切换、文件回退、恢复和卸载结果，保留原始错误及相关对象。刷新插件列表不重复刷日志。
