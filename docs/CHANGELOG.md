# 更新日志

## 1.0.0-dev - 开发中

1.0.0 不是给 0.9.8 换了个界面。桌面端、后台运行方式、设置、插件和发布包都重新整理过，旧 Qt 版也已经退役。下面只列实际使用时能感知到的变化。

> 目前仍是开发版，配置和界面可能继续调整。日常使用请先留在 Releases 页面提供的 0.9.8 稳定版。

### 升级前先看

- Windows 用户可以在首次启动时选择“迁移 0.9.x 旧版本数据”。角色、API 配置、聊天记录、长期记忆、TTS 资源、笔记、提醒和任务会在检查后一次性导入；旧目录保持不变，导入失败会回滚。Sakura 不会在后台自行扫描旧安装。
- 旧版迁移目前只支持 Windows，而且只能从首次启动入口进行。不要先把 1.0.0 配好再手工覆盖 `data` 目录。
- 全新安装不再暗中附带或选中默认角色。首次启动会带你导入角色，再设置 API 供应商和模型；这些步骤可以跳过，之后也能从“使用帮助”重新打开。
- 旧 Qt 桌宠、旧设置程序和 `start_studio.bat` 已移除。0.9.x 插件代码及插件私有数据不会直接搬进新版，插件需要使用适配 1.0.0 的版本重新安装。

### 新的桌宠界面

- 桌宠改为 Tauri 应用。设置、角色工作室、聊天历史和运行日志都在 Sakura 内打开，不再启动几套彼此独立的 Python 窗口。
- 透明区域现在可以正常点击穿透，拖动、缩放、切换立绘时也不容易再出现裁切、抖动或位置跳变。Windows、macOS 和 Linux 分别使用各自的窗口实现；Linux 当前仍需要从源码构建。
- 气泡和输入栏的大小、位置、字体及逐字速度可以预览后再保存。长回复在气泡内滚动，不会把整只桌宠越撑越高。
- Windows 11 输入栏可选纯色或实时高斯模糊；macOS 使用原生毛玻璃。原生效果不可用时会回到纯色，不影响聊天。
- 右键菜单新增持久化“保持置顶”，也可以直接打开历史记录和运行日志。

### 对话、角色与屏幕感知

- 发送、取消、等待和报错状态重新做过。模型请求失败时会显示可用的状态码和脱敏原因；后台意外退出后，已完成的回复和未发送草稿会留在原处，不会偷偷重发上一条消息。
- 日文原文、中文字幕、表情立绘和语音继续按回复分段同步。当前会话里的回复可以前后翻看，切换字幕后气泡会立即刷新。
- 新增只读聊天历史窗口，可以按当前角色向前翻页。切换角色会先停止当前回复、语音和插件任务，再载入新角色的历史与长期记忆，不会把两边的数据混在一起。
- 框选截图可以选择发送分辨率；高 DPI、Retina 和不同缩放比例的多显示器坐标已重新校准。定时屏幕观察和主动发言也迁到了新桌面端。
- 对话上下文会按所选模型的窗口大小装入近期聊天、屏幕观察和相关记忆，长对话不再只受一条很小的固定历史上限约束。

### 设置、记忆与语音

- 设置集中到一个窗口。可以保存多套 API 供应商，并分别给聊天、视觉和记忆整理选择模型；多数设置保存后可以原位生效，不必重启整个 Sakura。
- 长期记忆改用本地 ONNX 模型。即使没有聊天 API Key，已经保存的记忆仍可检索和手工编辑；初始化或存储出错时，普通聊天不会跟着卡死。
- 记忆页可以查看、筛选、新增、编辑和删除当前角色的记忆。模型下载或 ZIP 导入会显示进度，也可以取消，失败不会删掉原有缓存。
- TTS 改为插件提供。Sakura TTS Hub 统一管理语音能力，GPT-SoVITS 和 Genie 作为独立插件接入；切换语音设置、关闭程序或本地语音服务断开时，播放链会正常收尾。
- 角色工作室改为 Tauri 界面，可从设置中创建、编辑、导入和导出 `.char` 角色包。

### 插件与工具

- 插件改为各自独立运行。一个插件卡住或崩溃时，不会连带拖住聊天和其他插件；不同插件的 Python 依赖也不再挤在同一个环境里。
- 插件页可以安装、卸载、启停和修改插件自己的设置。官方的记忆、手机端、TTS Hub、Genie 与 GPT-SoVITS 插件随主程序提供；Playwright 浏览器改为按需安装，不再把 Chromium 塞进主安装包。
- 手机网页端插件共用桌面的当前角色、历史、模型和长期记忆。它可以发送文字或图片，但不能调用桌面工具或切换角色；请不要把端口直接暴露到公网。
- 通用 MCP Server 和内置 Web 搜索仍然保留，旧版自带的 Windows 桌面控制 MCP 已移除。
- 工具调用通过参数校验后会直接执行，不再逐次弹出确认框。插件与 Sakura 拥有相同的本机权限，只安装你信任的插件。

### 更新、日志与稳定性

- Windows Setup 和 macOS 安装版接入应用内更新；Windows Portable 会提示下载新的 ZIP。启动检查只负责发现新版本，不会自行下载、安装、退出或重启。
- 更新只替换程序文件，不会覆盖角色、配置、聊天记录、长期记忆和用户插件。正式包自带所需的 Python 运行环境，安装时不再临时运行 pip。
- 新增运行日志窗口，能查看本次启动中的聊天、模型、工具、截图、TTS 和插件状态，并复制已经脱敏的错误摘要。API Key、聊天正文和工具参数不会出现在普通日志里。
- Agent Prompt Trace 默认开启，只在本机保存中文可读记录，方便排查上下文和模型调用；它可能包含对话与记忆正文，不需要时可在“设置 → 系统”中关闭。
- 加固了后台进程退出、模型切换、插件重载、TTS 停止和错误恢复。某个可选能力失败时会明确显示原因，普通聊天仍可继续使用。

## 0.9.8 - 2026-06-21

### 本地快速接话

等完整回复的时候，Sakura 不用再沉默了。她会先接一句符合当前语气的短回应——比如你说了一长串，她先回个"嗯，我在听"之类的。可以在设置里调延迟、概率和语音，不喜欢直接关掉也行。

### 长期记忆升级

之前记忆是一锅粥，现在分成了几层：核心信息、经历、任务、操作习惯，各自归类。聊天的时候 Sakura 会自动翻出相关内容，也会在对话中悄悄更新记忆。重复和冲突的信息她会自己整理。

### 插件系统

插件系统重写了。现在插件可以注册工具、设置页、事件和渲染器，插件自己的设置也移到了独立窗口。管理页上能看到每个插件的版本、权限和状态。Playwright 浏览器插件继续带着。

> 旧版插件如果用的是 `sdk.*` 接口，升级后可能用不了，需要插件作者按新规范适配。

### 角色工坊

Windows 用户双击 `start_studio.bat` 就能打开。这是个图形界面的角色编辑器：新建角色、写人格卡、搭主题配色、拖立绘和参考音频进去，最后导出 `.char` 文件，别人也能导入用。

### 其他

- 增加默认关闭的 Windows Composition 实时玻璃技术 PoC 与安全降级诊断；实机验证已在当前
  Tauri/WebView2 HWND 上实现气泡和输入框的实时桌面高斯，并保持角色、拖动与截图路径，不使用截图模拟。
- 截图在高 DPI、多显示器和 Retina 下的错位和模糊修了。
- 点击桌宠就能叫出输入栏，不用每次都去找按钮。设置、历史和日志窗口现在有自己的任务栏图标，也不会被置顶的桌宠压住。
- 意外关掉重开，Sakura 会记得上一段聊了什么，不至于跟失忆一样。
- TTS 重做了底层，切换设置、退出程序和本地语音断开不会再崩。
- `0.9.8` 发布包不包含 `data/`，直接覆盖升级不会吃掉你的配置和聊天记录。
