# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.4

改进连续互动的回复衔接，支持插件活动记录，并修复语音启动与错误诊断问题。

- 支持插件连续互动时提前请求下一轮回复，字幕与语音按顺序接续；普通用户输入仍可打断，切换角色时清理旧回复。
- 插件可接收回复开始呈现和取消的通知，让互动动作跟随语音或文字显示。
- 历史记录支持插件活动摘要、展开详情和记录入口，写入活动无需请求模型或打断语音；系统记录逐条显示时间。
- 精简历史读取中的重复校验与数据复制。
- 保留模型请求失败的原始原因和完整日志关联编号，减少重复报错。
- 统一 SakuraTTS 的运行环境检查与服务启动路径处理，修复 Windows 路径前缀兼容问题并保留长路径支持。
