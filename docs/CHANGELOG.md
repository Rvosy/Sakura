# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.3

修复 SakuraTTS 运行环境的长路径问题，升级时保留已有环境、配置和模型缓存。

- SakuraTTS 默认运行环境和引擎缓存改到用户数据目录下的 `tts/sakura`，旧默认目录在启动时自动迁移。
- 迁移失败时继续使用现有环境，安装记录更新中断后可在下次启动恢复；目标已有缓存时保留两边内容。
- 保留用户指定的外部运行环境目录，默认目录随便携版用户数据一起移动。
- 缩短整合包内部目录，导入时去掉压缩包外层目录，并保留迁移失败后的修复入口。
- 修复重复插件迁移和旧数据导入配置的保留，改进角色启动、资源释放、关闭行为和错误诊断。
- 插件市场自动刷新目录并保留已有缓存。
