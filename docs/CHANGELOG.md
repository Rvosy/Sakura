# 当前发行说明

仅维护当前版本的发布正文，已发布版本见 [Releases](https://github.com/Rvosy/Sakura/releases)。

## 1.3.4

新增插件更新提醒和活动历史，支持连续互动中的回复接续，并修复 Windows 下的语音启动路径问题。

- **互动回复接续**：为五子棋等连续互动插件提供回复排队能力。上一轮还在说话时可以请求下一轮回复，生成的内容会等上一轮字幕和语音结束后再播放；普通聊天输入仍可打断。需插件接入此能力。
- **插件活动历史**：支持此能力的插件可将活动记入历史记录，方便查看摘要、展开详情或打开相关入口，回顾聊天之外的互动。
- **插件更新提醒**：开启自动检测更新后，角色会在会话空闲时提醒已安装插件的新版本。插件列表也会显示可更新数量和标记，可直接查看更新详情。
- **安装时选择统计设置**：Windows 安装器新增隐私说明和统计选项，新安装时可取消发送运行统计与错误报告；已有设置在升级时保留。
- **语音启动路径兼容**：修复 Windows 下部分目录中的 SakuraTTS 环境检查或服务启动失败问题，同时保留长路径支持。
