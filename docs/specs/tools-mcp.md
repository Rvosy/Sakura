# 工具、联网与 MCP

工具让 Assistant 在对话中执行具体动作。宿主负责注册、来源和实例边界，Assistant 负责选择与调用，插件负责真实业务、外部连接及任务资源。工具目录不能成为另一套聊天受理或模型服务。

MCP 是供插件复用的协议组件，联网和浏览器是各自的能力提供者。它们最终都通过明确的工具或服务契约接入，沿用[聊天](conversation.md)的取消、终态和角色边界。

## 职责与关系

| 参与者 | 职责 |
|---|---|
| 宿主工具服务 | 登记工具、提供目录、检查注册身份、路由真实调用 |
| Assistant | 按用户意图选择工具、组织参数、处理结果并继续模型循环 |
| 工具插件 | 执行动作，报告真实结果，管理创建的连接与资源 |
| MCP 组件 | 连接 MCP 服务、请求协议方法、转交进度与服务端交互 |
| MCP 消费者 | 保存服务配置、决定工具如何展示、处理授权和业务语义 |
| Artifact 宿主 | 管理明确交付的大内容及接收者实例 |

Core 只保留时间等通用宿主工具，领域能力由插件登记。启用一个基础组件不代表已经有具体工具，工具数量和名称由当前已安装、启用的提供者决定。

## 工具描述与注册

工具描述包含稳定名称、用途、JSON Schema 参数以及可选分组、风险和能力标签。描述应让模型理解动作与后果，不把内部函数名或含糊文案当作业务说明。

插件通过 `sakura.host.tools` 登记回调。外部贡献同名冲突会明确失败，不靠后加载覆盖已有工具。撤销只移除本次登记的对象，不能删除后来同名的新注册。

Assistant 获取目录时同时取得 registration ID。实际调用携带该身份和工具名称；插件重载后旧目录项失效，不能按名称转交给新提供者。

分组用于发现和选择，风险字段是元数据。当前工具由 Assistant 直接调用，不存在通用的逐次工具确认队列；插件需要的 OAuth 或其他业务交互由该插件按公开接口明确处理。

## 一次工具调用

1. Assistant 从当前目录选择符合本轮意图的工具，生成参数。
2. 宿主确认原注册仍有效，并调用对应插件回调。
3. 插件执行真实动作，返回 JSON 结果或允许的资源交付。
4. 宿主保留成功、内容、错误及原因码，Assistant 将结果关联到原工具调用。
5. Assistant 根据结果继续对话或结束；工具完成不直接代表整轮聊天完成。

执行日志应能关联本轮操作、工具名称、阶段、结果和必要耗时。插件返回失败或外部服务报错时保留诊断，不把失败变成空列表或空成功字符串。

默认 Assistant 遵守已配置的循环与调用额度。发现工具、获取参数和执行动作不是同一个结果，不能在额度已结束后偷偷继续执行下一步。

## 取消与外部副作用

取消停止本轮后续调度，并通知模型及可取消的在途任务。同步回调和外部服务可能已经执行，聊天取消不意味着这些副作用被回滚。

插件应把长任务设计为可查询、可取消并可释放的工作，绑定创建时的调用者 scope 与提供者实例。取消、释放或插件退出后，迟到结果不能回写新会话。

提供者崩溃、连接中断或调用超时后，不自动把旧调用重放给新进程。应保留“失败”或“结果未知”的事实，由实际恢复入口处理。

任务清理由创建者负责，不能要求用户继续打开窗口才能完成。外部独立服务不属于 Sakura 的进程树，退出时只关闭自己的连接。

## 工具图片与大内容

普通工具结果使用 JSON。当前图片工具可返回 `content` 与图片 Artifact 描述，描述包含 `artifactId`、`mediaType`、`byteLength`，不直接暴露任意本机路径。

宿主核对资源属于原工具提供者，再交付给实际调用者实例。Assistant 读取图片后释放接收资源；旧 scope 不能读取新任务资源，也不能通过伪造描述释放别人的文件。

这个图片封装不是任意文件结果协议。模型大请求、Assistant 结果和 Timeline 大页面使用各自明确的 JSON Artifact 契约；MCP 大结果使用自己的分段读取接口。

资源的拥有者、接收者和回收时机必须明确。临时交付完成不会删除历史录音、用户模型或其他持久化原件，相关约定见[语音](voice.md)与[插件运行](plugin-runtime.md)。

## MCP 组件与消费者

`sakura.mcp` 复用 MCP SDK，支持 stdio、Streamable HTTP 和 SSE。组件维护协议连接与异步任务，消费者使用统一服务，不再实现第二套传输。

消费者通过 `registerServer` 提交连接描述并取得 handle。stdio 使用命令、参数、环境和工作目录；远程连接使用 URL、请求头和代理。配置仍由消费者保存和展示。

组件没有独立的服务器管理页，也不会自动把所有远端工具注册到 Assistant。消费者决定服务用途、工具命名、结果处理以及是否开放具体能力。

连接在后台建立。连接 ready、某次请求完成和消费者插件 active 分别表达不同状态，不能互相替代。

## MCP 请求与交互

| 接口 | 业务含义 |
|---|---|
| `capabilities`、`status` | 查看组件能力和本消费者连接状态 |
| `begin` | 在指定 handle 上启动协议请求，返回操作 ID |
| `inspect` | 查看 running、completed、error 或 cancelled，以及进度和结果信息 |
| `readResult` | 分段读取较大的 JSON 文本结果 |
| `events`、`readEvent` | 读取连接通知与较大事件 |
| `readInput`、`respond` | 读取并回应服务端需要消费者处理的交互 |
| `cancel`、`release` | 请求取消与最终回收操作 |
| `unregisterServer` | 结束连接及其请求 |

工具、资源和提示词目录的分页游标按 MCP 协议继续传递。不能把第一页当成完整目录，也不能把一次读取到的片段当成全部结果。

`readResult` 的 offset 和 nextOffset 按字符计算，返回 text 与 done。消费者按返回位置拼接，处理中文等多字节内容时不能按 UTF-8 字节重新计算偏移。

OAuth 授权地址交给消费者展示。sampling 和 elicitation 由消费者明确启用、呈现并回应，组件不替用户自动同意。需要跨重载保存的 OAuth 凭据绑定消费者插件和完整服务地址。

## MCP 所有权与退出

连接、请求、通知、待响应输入和凭据都绑定消费者身份。其他插件以及同 ID 的新 scope 不能读取或取消旧实例的任务。

消费者结束操作后调用 release，放弃连接时注销 handle。取消请求和资源已经释放是两件事；任务仍在收尾时，组件继续持有并最终回收结果流和连接资源。

消费者停用或重载会撤销其连接与操作，不影响其他消费者。组件退出等待自己创建的协议任务结束，进程所有者保留最终回收责任，见[插件运行](plugin-runtime.md)。

## 联网搜索与页面读取

内置联网插件提供搜索和 URL 读取。搜索支持百度、Bing 和 Tavily，默认百度；Tavily 需要用户配置 API Key。搜索决策由 Assistant 作出，插件不额外请求一个模型替用户决定是否联网。

搜索结果包含标题、链接和摘要；页面读取提取正文，按请求的内容范围返回并标明截断。网络错误、服务拒绝或页面无法读取时保留具体原因，不把它表示成没有搜索结果。

后台页面读取不执行浏览器脚本，也不复用用户登录态，不能据此声称读到了登录后的内容。插件设置中的搜索测试使用草稿，关闭或更换对象后旧结果不回填。

停用联网插件只移除它的工具。其他插件仍可按自己的配置访问网络，不能把该开关解释成整个应用的离线模式。

## 浏览器能力

浏览器操作由独立插件提供，可以用于需要脚本、页面交互或可见操作的任务。后台搜索和浏览器页面操作保留不同来源，不互相伪装。

用户明确要求可见浏览器操作时，默认 Assistant 优先使用相应浏览器能力，不用后台抓取冒充已经在页面完成。导航成功后可以补充只读页面信息，但不能把导航本身当作内容已验证。

浏览器会话、页面和其创建的任务归所属插件管理。插件关闭后回收自己创建的资源，不关闭用户的无关浏览器或使用未取得的页面状态。

## 关键行为

- 工具同名替换后，旧调用明确失效，不执行新插件的动作。
- 工具已经产生外部效果后取消聊天，不自动重放或宣称撤销了该效果。
- 一个 MCP 消费者重载，不断开其他消费者的连接。
- 大结果包含中文时，分段读取仍完整且不重叠；读取完毕后释放保留流。
- 未显式开启的 sampling 或 elicitation 不被组件自动接受。
- 网页读取失败会显示原原因，不能变成“没有相关信息”。
- 图片工具交付给原调用实例，插件重载后的新实例不能读旧图片。

任务失效原则见 [ADR：显式生命周期](../adr/explicit-lifecycle.md)，临时媒体交付见 [ADR：媒体资源归属](../adr/media-resource-ownership.md)。实现入口为[宿主工具服务](../../app/core_host/plugin_host_services.py)、[默认 Assistant](../../plugins/builtin/sakura_assistant/)、[MCP 组件](../../plugins/builtin/sakura_mcp/) 和[联网插件](../../plugins/builtin/sakura_web/)。

公开调用示例见[插件能力接入](../development/plugin-recipes.md#接入-mcp)。
