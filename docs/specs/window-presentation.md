# 窗口、渲染与回复展示

表现模块把已完成的聊天结果呈现为字幕、语音和角色动作，并让透明桌宠在各平台上保持可见、可点击、可拖动。它不决定回复内容，不写聊天事实，也不把界面动画完成当作聊天业务完成。

## 职责与模块联系

| 模块 | 负责 | 依赖与输出 |
|---|---|---|
| Core 聊天边界 | 已提交回复、角色与操作身份 | 向前端交付原始段落及历史身份 |
| 表现宿主与插件 | 控制解析、持续状态、一次动作、渲染模块 | 使用当前角色资源和固定绑定，不跨角色执行控制 |
| 回复展示器 | 当前段落、字幕、等待与回看状态 | 协调表现准备和 TTS Hub 的播放流程 |
| TTS Hub 前端贡献 | 分段合成与实际播放协调 | 调用 Core 授权语音，再由 Shell 播放 |
| 布局与命中模块 | 可见范围、控件区域、锚点与命中语义 | 把前端逻辑几何转成平台原生窗口和输入区域 |
| 平台窗口与材质后端 | 系统级穿透、拖动、表面大小与原生玻璃 | 报告实际生效能力，不能改写用户的选择 |

角色资源和编辑见[角色规格](characters.md)，语音资源与录音所有权见[语音规格](voice.md)。表现插件的具体接口集中在[开发接口](../development/characters.md)。

## 绑定与首次显示

角色表现包含当前 generation、角色、resourceId、bindingId 与提供者身份。渲染器只处理这一绑定的资源和控制；同一资源 ID 在重新加载后也不代表原绑定仍有效。

宿主加载插件声明的模块，在独立容器挂载并等待必需资源就绪。候选准备期间协调旧画面和窗口表面；新画面就绪后再交接，过渡期间同时容纳新旧可见区域，结束后收紧。

用户要求减少动画时直接切换，不以动画作为功能前提。关闭、重新绑定或插件实例失效后，中止对应 signal、任务与监听；迟到挂载的实例仍要销毁，不能留在后台继续更新原生窗口。

没有可用表现时保留公共资料、输入和文字聊天入口。首次表面尚未提交成功前不显示错误位置的窗口；资源、模块或渲染错误显示具体原因，不冒充角色尚未配置。

## 一条回复的展示流程

1. Core 提交聊天回复后，前端接收有序 segments。保留原始 segmentIndex，显示时跳过空文本不重新编号。
2. 为下一段准备语音和表现控制。控制说明来自当前资源，解析使用生成回复时固定的绑定数据。
3. 有语音时以原生播放 started 为本段开始信号，同步开启字幕与表现；静音段按文字展示流程开始。
4. 本段的播放和字幕展示结束后，按当前停留设置进入下一段；提前完成的准备结果只用于对应段落。
5. 全部展示完成后进入可回看状态，保留已经实际展示的持续画面，不重复执行一次性动作。

模型生成、回复提交、语音合成和音频播放分别有自己的结果。正文提交不等待可选表现解析或 TTS；音频设备不可用、合成失败或本段禁止 TTS 时，文字继续显示。

取消当前互动使旧展示失效；跳过逐字显示只改变字幕，不取消已提交回复。新操作、角色切换或绑定变化后，旧定时器、音频事件和控制解析不得更新当前段落。

用户开始录音时打断当前语音，并使该次回复的后续展示保持静音；录音结束不补播已经跳过的声音。新播放操作可以停止旧音频，但不能靠旧音频结束事件推进新回复。

## 持续状态、动作与回看

| 内容 | 作用与重放规则 |
|---|---|
| 持续状态 state | 当前姿态、表情等可恢复状态；同一段实际展示后可保存快照 |
| 一次动作 actions | 挥手等瞬时行为；本次操作执行一次，不因重绘、恢复或回看再次执行 |
| 原始控制 | 关联资源及生成时的绑定，保留供本段解析，不跨绑定重新解释 |
| 语音录音 | 以历史条目和原始段落下标关联；回看画面不自动播放 |

渲染器的 snapshotState 返回可重新交给 applyState 的完整持续状态。回看使用当时实际展示结果，不重新调用模型、不重算随机动作，也不调用 perform。

气泡回看限于当前运行已经展示的回复段落，且在回复展示已经结束或出错后进行；它不等于数据库历史窗口。历史窗口可以独立请求某条历史段落的录音，仍不执行该段表现动作。

控制解析或一次动作失败只影响对应表现。可保持的稳定画面继续保留，文字与语音不因此丢失；整个绑定不可用时报告资源状态，不向另一个形态投递旧控制。

## 字幕与气泡

字幕支持中文、日文及两种双语排列。中文优先译文、缺少译文时使用原文；日文使用原文；双语按主辅语言配对换行，去除空项和相同的重复文本。

断行根据完整段落和当前可用宽度计算，再逐字展示，不随着半个单词不断跳行。原文与译文同时推进；字体或宽度变化后重新排版，但不改变段落内容和语音身份。

语言选择保存后立即更新当前可见回复和已打开历史窗口。正在逐字显示的当前段按新语言重新展示，已经完成的段直接替换文字，不重播语音、不执行动作、不切换形态。

气泡保持用户设置的固定外框高度，长内容在内部滚动。自动滚动尊重用户正在查看的位置；选中文字、滚动条和输入框是交互区域，不能被拖动逻辑抢走。

等待、错误和取消提示属于运行状态，不伪装成新的角色回复。用户输入法组合期间不触发发送；发送成功受理后只清除本次提交的内容，后续新输入保留。

## 几何、锚点与可见范围

布局使用统一逻辑坐标，Shell 根据内容缩放和显示器比例换算物理坐标。桌宠锚点绑定角色底部中心；窗口原点和舞台偏移共同维护该锚点，不能因为重新测量、表情切换或气泡伸缩不断积累位置误差。

全局坐标保留正负值，支持位于主屏左侧或上方的显示器。像素边界向外取整，使可见内容不被舍入裁切。首次放置可约束到工作区，用户拖动后的真实落点优先，普通布局变化不再次把角色拉回屏幕边缘。

可见范围与鼠标命中是两份信息。可见范围决定窗口需要容纳什么，命中决定哪里接收鼠标；一个包围矩形不能同时代替两者。气泡、菜单、输入栏和动态形态都参与各自范围计算。

表面提交带 revision。原生窗口变化与 WebView 的舞台偏移、指针坐标和视觉效果使用同一份几何，旧返回不能覆盖新布局。提交失败保留最后有效状态，不把半次更新当成完成。

连续缩放或布局预览在手势期间保留足够包络，按最新值更新，中间帧不反复完成整套窗口重建；手势结束提交最终几何。取消、失焦和拖动结束都要结束对应手势，不能留下永久放宽的区域。

## 命中、拖动与显隐

| 区域 | 行为 |
|---|---|
| interactive | 输入、选择文字、按钮与滚动；优先于角色拖动 |
| drag | 允许拖动角色或界面空白位置 |
| neutral | 属于窗口但不触发拖动或具体控件操作 |
| transparent | 鼠标交给后方应用 |

立绘按透明信息判断命中，动画模型可以使用当前点的动态命中。全透明立绘合法，气泡、输入栏与菜单仍能操作。DOM pointer-events 只决定 WebView 内部路由，最终跨应用穿透由原生平台实现。

淡入淡出期间命中与可见范围覆盖仍可见的新旧画面，结束后收紧。隐藏控件不留下不可见的鼠标遮挡；控件显示与原生材质显隐同步。Windows 输入栏悬停唤出同时考虑角色、气泡和输入栏的有效位置，区域间空隙不属于唤出范围。

拖动和右键菜单的点击区域由前端判断，原生端执行已受理的操作，不因布局版本变化或重复像素命中检查拒绝。原生悬停位置暂时不可读取时保留当前悬停状态，恢复后继续更新。

输入框有焦点、已有文本或附件操作尚未结束时维持可操作状态。打开菜单临时扩展需要的输入区域，关闭后恢复之前的窗口与锚点；子菜单靠近屏幕边缘时在可用方向展开。

## 平台行为与材质

| 平台 | 原生表面和输入 | 当前输入栏材质 |
|---|---|---|
| Windows | 原生区域与透明命中，预览期间保持稳定包络 | Windows 11 支持纯色、高斯玻璃；Windows 10 使用纯色；液态玻璃未作为完成能力开放 |
| macOS | AppKit 表面与鼠标穿透，几何在主线程一次提交 | 纯色、系统高斯；macOS 26 支持系统液态玻璃 |
| Linux | 原生输入范围使用裁过透明边的矩形，WebView 再判断像素 | X11 支持纯色和高斯模糊，输入栏停下后采样一次合成画面；Wayland 使用纯色。液态玻璃不可用 |

用户请求的材质与实际生效材质分开保存和展示。Windows 已存液态偏好、旧版 macOS 的液态偏好或原生效果失败时可以用纯色继续使用，保留原选择与原因，不把另一种玻璃偷偷当作所选效果。

macOS 原生材质使用公开 AppKit 能力，不要求额外屏幕截图权限。Windows 的未完成实验开关和渲染代码不代表用户已经具备液态效果；可选材质失败不能影响输入、拖动、关闭或正常系统截图。

Linux 不把立绘的海量像素矩形直接交给 GTK 原生区域。设置中当前不提供实时角色立绘预览，改选形成草稿，应用后切换。X11/XWayland 可按需要调整位置；原生 Wayland 的绝对位置由合成器决定，诊断不能声称定位成功。

X11 的高斯模糊只覆盖输入栏。采样前先把输入栏自身清成透明，避免拍进上一帧；画面在输入栏停下后更新。Wayland 无法采样时有效模式为纯色，原来的高斯偏好保留，运行日志记下原因。Windows 的实时模糊不走这条采样路径。

## 关键业务例子

| 场景 | 预期结果 |
|---|---|
| 段落语音合成失败 | 该段静音显示文字，后续段落按自身结果继续 |
| 回看曾播放过的挥手段落 | 恢复当时姿态，不再次挥手或播放声音 |
| 在副屏负坐标位置缩放角色 | 底部锚点稳定，过渡不裁切，旧几何不把角色拉回主屏 |
| 完全透明形态仍有输入框 | 透明处穿透，输入框和菜单仍可使用 |
| 用户选择液态玻璃但平台不支持 | 保留偏好，明确显示当前纯色及限制，正常聊天不受影响 |
