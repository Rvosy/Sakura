# 界面设计规范

设置页的视觉规则用于参数编辑界面。角色工坊、聊天记录和运行日志按各自用途组织信息，共用主题色、控件和反馈方式，不统一套用标题区、分割线和布局。

## 适用范围

| 界面 | 设计边界 |
|---|---|
| 设置 | 采用本文的标题、卡片、间距、底栏与切页动效 |
| 角色工坊 | 顶部用紧凑工具栏选择角色，下方按栏目展示原有资源卡片和编辑内容 |
| 聊天记录 | 保留现有阅读布局、角色标识和动效，不添加设置页的标题分割线 |
| 运行日志 | 围绕筛选、状态和诊断记录组织内容，标题与工具栏单独设计 |

修改现有界面以局部调整为主。保留卡片、控件位置和操作流程；复用组件前，先确认它在两个页面中承担相同用途。共享样式的改动需要检查引用它的窗口，不能把一个页面的布局决定自动扩展到其他页面。

## 设置页的标题与间距

页面主标题使用 22px、粗体、主题主文字色。标题区底部保留一条 1px 的细分割线，颜色使用 `--hairline`。标题与内容左侧对齐，线下到内容留出 16–20px。

标题上边距为 16–18px、下边距为 4px，内容左右边距为 18–22px，随窗口宽度变化。分组卡片内边距为 14–16px。

导航组依靠小标题和留白区分，不加组间横线。插件管理保留标题、标签页与操作合并的工具栏，不额外插入重复标题。

侧栏的 Sakura 名称居中，导航项目保持左对齐。模型服务详情中的服务名称使用 20px、半粗体，与下方表单留出 20px 间距；API 服务和账号服务采用相同层级。

卡片边框用于区分独立区块，继续保留。区块内部只在不同任务或内容层级确实需要区分时使用分割线，不给每个字段、每组导航或每段说明都画线。

## 角色工坊的工具栏与标题

角色选择属于编辑工具栏。标签、选择框和操作按钮排在同一行，集中靠左排列；选择框和按钮高 36px，角色名用 14px 普通控件字号。选择框常态显示边框、底色和下拉箭头，悬停与键盘焦点有明确反馈。窄窗口压缩间距和选择框宽度，长名称省略显示。

工具栏下方保留一条细分割线，区分角色操作与当前栏目。“基础信息”“角色形态”等栏目标题使用 20px、半粗体，下方不再加横线。标题与内容左侧对齐，标题下到内容留出 12px。

侧边导航、资源卡片、编辑表单和底部操作的位置沿用原有布局。角色选择不承担大标题的视觉权重，也不因窗口变宽把相关按钮分散到两端。

## 颜色与卡片

颜色来自当前角色的主题。页面底色、面板、卡片和输入框分别使用已有主题变量及其混合色，不写死浅色背景。深色主题使用相同结构和层级。

设置页保留 16px 的外层圆角、11px 的分组卡片圆角和 9px 的控件圆角。其他窗口已有的聊天气泡、记录行和资源卡片按用途保留。

文字依次使用主文字色、次级文字色和提示文字色。主操作使用主题色，危险操作保留独立的危险状态。选中、悬停和焦点通过颜色、边框与焦点环表达，导航标签切换后保持原位。

## 设置页的底栏与滚动

操作底栏和外层面板同色，不加常驻顶部分割线。内容还被底栏遮住时显示轻微上缘阴影；到达底部、内容变短或切换到短页时消失。

具有独立滚动区域的列表或编辑面板由自身边界区分，不在外层底栏重复加阴影。底栏按钮的位置和保存含义由各模块保留。

滚动、窗口缩放和内容高度变化都应更新遮挡提示。切换页面后观察新页面，关闭窗口时释放观察器。

## 设置页动效

动效按操作用途选择，避免整页、标题和卡片同时叠加位移。

| 用途 | 处理方式 |
|---|---|
| 同级页面、插件详情切换 | 原位淡入，200ms、`ease-out`，透明度从 0.5 到 1；标题与内容同步，不逐卡片错峰 |
| 再次点击当前页 | 保持当前内容，不重播标题动画 |
| 设置弹窗 | 淡入配合轻微缩放，约 0.98–1；不把整张弹窗从下方推上来 |
| 下拉菜单 | 从触发位置短距离展开，位移约 4px |
| 进度、刷新和状态变化 | 保留能说明状态的动效，不连带移动整个页面 |

系统要求减少动态效果时，同级页面直接显示。动画不能延迟内容可用、抢走焦点或承担唯一的状态提示。引导流程的前进、返回，以及聊天、日志等窗口的内容更新动效按各自用途处理。

标题与内容的组织参考 [WinUI Gallery 设置页](https://github.com/microsoft/WinUI-Gallery/blob/main/WinUIGallery/Pages/SettingsPage.xaml)；按用途选择过渡的原则参考 [Fluent 2 动效指南](https://fluent2.microsoft.design/motion)。本页的尺寸、分割线与时长是 Sakura 设置页的具体约定。

## 实现入口与检查

[设置样式](../../desktop/frontend/settings/styles.css)负责主题、标题、卡片、控件、底栏和切页动效；[设置控制器](../../desktop/frontend/settings/settings.js)负责导航和底栏的滚动状态。工坊也引用这份基础样式，修改公共选择器时需要核对工坊的影响范围，专属布局在[工坊样式](../../desktop/frontend/studio/styles.css)中处理。

检查浅色、深色、窄窗口、长短页面、滚动到底和快速连续切页。表单输入、保存、菜单及弹窗仍需正常使用。布局调整用浏览器核对，不把像素位置或样式源码写成业务测试。
