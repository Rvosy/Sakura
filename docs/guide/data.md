# 数据、备份与迁移

在“设置 → 系统 → 用户数据”查看并打开当前数据目录。

| 使用方式 | 默认位置 |
|---|---|
| Windows 安装版、Portable | Sakura 目录 |
| macOS | `~/Library/Application Support/Sakura` |
| Linux | `${XDG_DATA_HOME:-$HOME/.local/share}/Sakura` |

开发版可使用独立的 `Sakura Development` 数据目录，以设置页显示的实际位置为准。

## 保存与备份

更新程序保留角色、配置、聊天、记忆与用户插件。局部设置保存只改本次提交的内容，未提交字段和显式配置保持原值。

备份前正常退出 Sakura，复制完整用户数据目录。聊天和记忆使用数据库，运行中只复制某个数据库文件可能遗漏尚未合并的写入。恢复时同样先退出程序。

TTS 资源默认在用户目录的 `tts/`，可以选择已有可写目录。更改位置不自动搬移文件；外置盘断开时报告存储不可用，不偷偷改用默认位置，文字聊天仍可用。语音缓存有独立的目录与容量设置。

## 导入导出聊天记录

在聊天记录窗口右上角的“更多操作”菜单中选择“导入聊天记录”或“导出聊天记录”。记忆的入口在“设置 → 记忆 → 高级设置”，在“备份或迁入记忆”右侧打开“更多操作”，即可导入或导出当前插件的记忆。

导出时按用途选择“迁移与恢复”或“阅读与分享”。聊天默认选择当天。点击“日期范围”打开居中的选择窗口，可选择当天、近 7 天、近 14 天、近 30 天或全部，选择后仍可修改起止日期，确认后应用。“全部”填入当前角色已有记录的最早和最晚日期；暂无记录时显示提示。日期按年/月/日分段输入，输入完成自动跳到下一段，月份和天数限制在有效范围内，也可直接在月历中选择。范围包含开始和结束当天；取消会保留原范围。

- Sakura JSON 用于迁移和恢复，保留条目身份、原始时间、聊天段落、翻译及记忆属性。
- TXT 用于查看、复制和分享，不能还原条目身份和原始时间；其中的正文可以复制到“从文本提取记忆”重新整理。

聊天、长期记忆和便签分别导出为文件。默认文件名为 `history_<角色ID>` 或 `memory_<角色ID>`，扩展名按所选格式使用 `.json` 或 `.txt`。导入记忆前安装并启用对应插件；文件不能在不同记忆插件之间直接转换。文件不含角色资源包、图片原件、语音录音或模型权重。

导入前显示文件名、新增、重复和冲突数量，可以更换文件，确认后合并到当前角色。重复记录跳过，冲突保留本地内容。来自其他角色的文件会显示来源和目标，确认后复制到当前角色，原角色数据保持不变。

旧聊天按原始时间显示，导入不会重放对话、语音或工具，也不会自动重新整理为记忆。长期记忆插件直接恢复记忆正文和属性，用本机向量模型重建检索索引，不调用整理模型。文件迁移不替代完整用户目录备份。

长期记忆插件的正文导入在本地事务中完成；失败时保留原记录。向量索引随后更新，失败可在记忆页重建。JSON 同时保留证据和删除标记，TXT 只导出未删除的正文。

“设置 → 记忆 → 高级设置 → 从文本提取记忆”支持粘贴笔记、旧记忆正文和聊天片段。点击“提取候选”后，核对每条的内容、对象、用途和原文依据，可以修改或取消勾选，再点击“保存所选记忆”。这一步使用所选记忆整理模型；提取失败或停止时保留输入，确认前不会写入记忆。确认后的条目作为手动记忆保存，来源标为“导入文本”，不会添加到聊天记录。JSON 备份仍使用导入功能直接恢复。

更新现有安装并沿用原用户数据目录时，长期记忆插件会自动迁移该目录中的旧记忆，无需先导出再导入。原有 ID、正文、时间、证据和删除状态继续保留；缺少对象信息的旧事实显示在“共同经历”的未分类内容中，旧画像保留在“个人画像”中。迁移不会猜测关系或调用模型改写旧内容。换安装目录或搬到另一台电脑时，使用下面的旧版数据导入入口。

想从导入的聊天中补充记忆，可在“设置 → 记忆 → 高级设置”中展开“从旧聊天补充记忆”，填写开始与结束日期，启动整理。取消后再次启动同一范围会继续，已处理的原文不会重复写入。此操作使用所选记忆整理模型。

## 导入旧版数据

Sakura 不在普通启动时自动扫描其他旧目录。需要迁移时先退出旧版，在首次设置的“迁移旧版本”，或“系统 → 用户数据 → 迁移旧数据”选择旧目录。

先检查能识别的角色、聊天和记忆，再核对角色关联以及新增、重复和冲突记录。存在覆盖时需要确认，已经使用新版也可以增量导入。导入保留可识别的数据，平台不兼容的语音运行环境可跳过；不要用旧 `data/` 直接覆盖新版。

旧角色包保留人设、表现和语音资源。新导入角色不继承包内语音启用与引擎选择，需在本机选择；升级已有安装则尊重已有启停偏好。

失败时查看具体步骤和错误，保留原目录与恢复材料后重试。导入旧版长期记忆或外置语音配置前，先安装对应的长期记忆、GPT-SoVITS 或 Genie 插件；导入器复用已安装插件的兼容工具。插件安装见[插件指南](plugins.md)。

## 删除与清理

删除角色包保留聊天和记忆，卸载插件保留其数据。语音缓存按容量清理较早的非收藏录音，收藏保留。

仓库的 `tools/cleanup.py` 默认预览，核对列表后使用 `--apply` 执行。不要手工删除正在使用的数据库或锁文件。日志与错误报告的内容和保存规则见[诊断](diagnostics.md)及[隐私](privacy.md)。
