# 数据、备份与迁移

在“设置 → 系统 → 用户数据”查看并打开当前数据目录。

| 使用方式 | 默认位置 |
|---|---|
| Windows 安装版、Portable | Sakura 目录 |
| macOS | `~/Library/Application Support/Sakura` |
| Linux | `${XDG_DATA_HOME:-$HOME/.local/share}/Sakura` |

开发版可使用独立的 `Sakura Development` 数据目录，以设置页显示的实际位置为准。

## 保存与备份

更新程序保留角色、配置、聊天、记忆与用户插件。局部设置保存只改本次提交的内容，未提交字段和显式配置保持原值。

备份前正常退出 Sakura，复制完整用户数据目录。聊天和记忆使用数据库，运行中只复制某个数据库文件可能遗漏尚未合并的写入。恢复时同样先退出程序。

TTS 资源默认在用户目录的 `tts/`，可以选择已有可写目录。更改位置不自动搬移文件；外置盘断开时报告存储不可用，不偷偷改用默认位置，文字聊天仍可用。语音缓存有独立的目录与容量设置。

## 导入旧版数据

Sakura 不在普通启动时自动扫描其他旧目录。需要迁移时先退出旧版，在首次设置的“迁移旧版本”，或“系统 → 用户数据 → 迁移旧数据”选择旧目录。

先检查能识别的角色、聊天和记忆，再核对角色关联以及新增、重复和冲突记录。存在覆盖时需要确认，已经使用新版也可以增量导入。导入保留可识别的数据，平台不兼容的语音运行环境可跳过；不要用旧 `data/` 直接覆盖新版。

旧角色包保留人设、表现和语音资源。新导入角色不继承包内语音启用与引擎选择，需在本机选择；升级已有安装则尊重已有启停偏好。

失败时查看具体步骤和错误，保留原目录与恢复材料后重试。导入旧版长期记忆或外置语音配置前，先从插件市场安装对应的 Mem0、GPT-SoVITS 或 Genie 插件；导入器复用已安装插件的兼容工具。插件安装见[插件指南](plugins.md)。

## 删除与清理

删除角色包保留聊天和记忆，卸载插件保留其数据。语音缓存按容量清理较早的非收藏录音，收藏保留。

仓库的 `tools/cleanup.py` 默认预览，核对列表后使用 `--apply` 执行。不要手工删除正在使用的数据库或锁文件。日志与错误报告的内容和保存规则见[诊断](diagnostics.md)及[隐私](privacy.md)。
