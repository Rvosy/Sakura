# 隐私政策

## 安装与选择

Windows 安装器在欢迎页展示隐私说明。“发送运行统计和错误报告”默认勾选，新安装时可以取消；取消后首次启动就不发送。安装到已有配置的目录会保留原设置。自动更新不改变这一选择。

完整政策随安装器提供，可在安装页离线打开。免安装版和其他平台可在应用设置中关闭统计。

## 模型、屏幕与语音

聊天会把本次输入和所需上下文发送到用户配置的模型服务。启用屏幕感知或主动发送截图时，截图也会发送到相应模型服务；关闭屏幕感知可停止定期截图。模型服务处理和保存这些内容的规则由对应服务商的隐私政策决定。

语音识别和合成按启用的插件及配置处理音频、文本和参考音频。本地引擎在本机处理；配置远程服务时，相应内容会发送到该服务。使用前应查看所选服务的隐私政策。

联网搜索、浏览器、MCP 和其他可选插件可能把执行任务所需的内容发送到目标网站或服务。用户可在插件设置中停用对应能力。角色、聊天记录、配置和插件数据保存在用户目录，数据位置与删除方式见[数据管理](data.md)。

## 运行统计与错误报告

Sakura 默认发送运行统计和错误报告，用于定位故障、版本兼容和模型请求问题，不需要登录。可以在“系统 → 匿名统计”关闭“发送匿名统计数据”；关闭后停止发送并删除本机待发错误报告，其他功能不受影响。

统计和错误报告发送到项目的诊断服务 `https://telemetry.cialloo.cn`。关闭统计不会关闭用户主动使用的模型、语音或联网服务。

## 发送内容

错误报告保留原始报错、异常原因链、调用栈、源码位置和恢复操作的错误，还可能包含实际路径、请求目标 URL、模型名称、HTTP 状态、子进程输出、失败阶段与耗时，以及错误前最多 40 条相关事件。

因此，原始错误可能带本地用户名、目录或失败数据片段。API Key、Authorization、Cookie、密码、token 和 URL 登录凭据按具体值替换，其他诊断内容保留。不同原因分开记录，完全重复错误可以累计次数。

运行统计记录版本、构建、系统架构、随机关联 ID，以及启动、聊天、语音、迁移等操作的结果。模型指标记录用途、耗时、结果、Token 用量与上下文估计，服务商实际用量与本地估计分开。

统计不主动收集整段聊天、提示词、记忆、完整模型回复、工具输入输出、图片、音频或局部变量，也不上传完整运行日志和 Agent Trace；原始错误中的失败片段按上述规则保留。

## 暂存与删除

错误报告发送前暂存在 UI 配置同级的 `telemetry-pending-errors/`，最多 64 份、每份 128 KiB、最长 7 天。发送成功删除，网络失败保留并在后续启动或空闲时重试，容量满时移除最旧记录。普通统计和模型指标不落盘补传。

诊断 ID 随机生成，不绑定账号或硬件。重新生成 ID 会清理旧 ID 的本机待发报告，只影响后续发送；服务器原始记录最多保存 90 天，通过受保护的管理端查看和导出。

## 语音兼容性

启用统计时，SakuraTTS 报告引擎启动、模型预加载和合成的结果、取消与耗时，并附整合包版本、请求与实际后端、推理档位和休眠模式。能获取时包含首张 NVIDIA 显卡名称、显存和驱动版本，不一定是实际用于推理的显卡。

这些统计不额外发送合成文本或音频，关闭统计后同样停止。取消不计为失败，未收到结果也不计为成功。

本机日志与 Agent Trace 的内容见[诊断指南](diagnostics.md)。
