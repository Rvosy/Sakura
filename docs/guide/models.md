# 模型服务与模型

Sakura 通过模型服务插件连接 API。默认提供 OpenAI 兼容接口，需要服务商的 Base URL 和模型名称；服务要求认证时填写 API Key，局域网等无需认证的服务可留空。

## 获取模型服务信息

在服务商的开发者控制台或 API 接入文档中，确认 API 地址、密钥和模型 ID 来自同一服务。网页聊天会员不一定包含 API 额度，请单独查看服务商说明。使用中转服务时，以该服务的接入说明为准。

首次配置可按[图文教程](setup.md#配置模型服务和模型)操作。获取模型列表和测试连接会请求服务商，可能消耗 API 额度。

## 添加和使用

1. 打开“设置 → 模型服务”，添加连接并填写 API 地址，通常以 `/v1` 结尾。
2. 手动添加准确的模型 ID，或获取模型列表后勾选需要的模型。
3. 测试连接。获取列表和测试都可使用尚未保存的配置；连接测试检查列表中的第一个模型。
4. 打开“模型”，为对话和视觉对话选择模型，再应用或保存。

可以保存多套连接。修改一套不影响其他连接，模型选择与连接密钥分别保存。密钥选择“保留”时沿用原值，“替换”写入新值，“清除”删除已保存值。

正在运行的请求继续使用原配置，新配置在应用后用于后续请求。当前对话未结束时，可以保存并等待它结束再应用。保存失败时保留编辑内容。

## 模型用途

对话模型处理文字聊天和工具调用；视觉对话模型处理截图和图片。图片请求必须由支持图片的模型处理，不能静默丢弃图片后继续文字聊天。

记忆等插件可增加自己的模型用途。选择继承对话模型时，跟随对话模型变化。停用服务或删除模型后保留原选择并标为不可用，便于重新启用或更换；其他用途不受影响。

在模型参数中填写上下文窗口、图片与工具调用能力。不确定的能力保持未知，窗口大小按服务商说明填写。对话生成参数包括温度、Top P 和最大输出 Token。

## 常见问题

| 现象 | 检查内容 |
|---|---|
| 401 | 密钥是否正确、已保存 |
| 403 | 账号权限和服务限制 |
| 404 | API 前缀与模型 ID |
| 429 | 服务商额度或限流 |
| 文字成功、图片失败 | 视觉用途是否选了支持图片的模型 |
| 连接被拒绝 | 服务地址、系统代理与服务运行状态 |

测试一个模型成功不代表其他模型或图片输入都可用。失败时可取消或调整配置后重试，具体错误见[运行日志](diagnostics.md)。密钥保存在本机，界面不回显完整值；公开日志前检查错误详情。
