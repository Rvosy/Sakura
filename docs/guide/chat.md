# 聊天、截图与语音

在桌宠输入栏输入并发送消息。发送过程中可以取消，取消会停止本轮模型请求及仍在运行的工具，已完成的对话保留。后台服务重启不会自动重发输入草稿。

## 截图与主动搭话

输入栏左侧 `+` 提供截图、框选截图及插件动作。图片附到下一条消息；取消框选不留下附件。图片消息需要支持图片的模型，配置见[模型指南](models.md)。

在“交互 → 主动屏幕感知”中设置开关、搭话间隔、截图间隔、截图上限和分辨率。Sakura 截取鼠标所在屏幕，固定分辨率只缩小、不放大小屏幕。聊天或上一轮任务忙时跳过本轮检查，睡眠恢复后不补跑积压任务。

截图暂存在内存中，空闲时将当前批次的最近画面交给模型。聊天完成、取消、失败或后台重启后，临时截图失效。记录保留文字观察与必要信息，不保存图片内容。截图可能包含其他应用的私密信息，会发送给所选模型服务。

## 历史与上下文

从桌宠右键菜单或托盘打开当前角色的聊天记录，向前加载更早内容。文字、角色回复、屏幕观察与语音留存按所属对话关联；角色之间的数据分开。气泡还可以翻阅当前运行会话中已完成的回复。

点击聊天记录右上角的日历图标，在弹出的日历中选择日期，即可定位到当天零点之后的第一条记录。继续向上或向下滚动会加载相邻记录，可以跨日期浏览。日历用左右箭头切换月份，按 Esc 或点击日历外关闭。有记录的日期数字会加粗，并显示主题色和浅色背景；标记只包含当前角色的记录。当天没有记录时会提示，保留当前阅读位置。查看旧记录时，右下角的“回到最新”可以返回最近的聊天；需要重新读取时，使用“更多 → 刷新记录”。

点击右上角的搜索图标，或按 `Ctrl+F`（macOS 为 `Cmd+F`），输入聊天内容后按 Enter。结果显示发言方、时间和高亮片段，点击即可定位到原消息，继续上下浏览完整聊天。“返回结果”保留搜索列表的位置；输入框内的叉号清空关键词，再次点击搜索图标或按 Esc 收起搜索，保留当前聊天位置。搜索范围与匹配规则见[历史读取](../specs/timeline-memory.md#历史读取与快照)。

模型上下文结合近期对话、最近两小时内成功分析的屏幕观察、可用记忆和当前状态。历史屏幕观察标明为程序提供。内容超过模型预算时，优先保留系统提示、当前输入和最近的完整对话；省略的旧内容仍留在本地记录中。

## 语音输出

在“语音”中开启当前角色语音，选择已启用的引擎并配置资源或服务地址，测试后保存。关闭语音后，文字聊天与字幕照常工作。SakuraTTS 随应用提供，其他引擎按需安装，见[插件指南](plugins.md)。

字幕可选择中文、日文或双语排列；切换语言只改变显示，不重复播放，缺少译文时显示原文。

聊天记录支持分段朗读和停止。优先播放已有录音，缺失或损坏时使用当前语音配置重新生成；有效录音无需启动引擎。语音缓存可设置目录和容量，清理时保留收藏录音，更改目录不自动搬移文件。

“空闲补齐”默认关闭。开启后在设备空闲且缓存有余量时补充缺少的历史录音，只生成缓存，不自动播放；用户语音请求优先。

## 语音输入与记忆

安装 SenseVoice 等识别插件并准备模型，在语音输入设置中选择引擎、语言和麦克风。点击麦克风开始录音，再次点击停止并识别。识别结果写入草稿，由你确认发送；取消保留原文字和附件。

长期记忆由插件提供。Mem0 需要本地向量模型，模型初始化期间普通聊天仍可继续。记忆页可搜索、增删和编辑，编辑后需要保存。未选择整理模型时，手动管理和已有记忆召回仍可用。

遇到问题先看[故障排查](diagnostics.md)，数据保留与迁移见[数据管理](data.md)。
