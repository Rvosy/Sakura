# 插件与资源

插件扩展聊天、模型、语音、记忆、工具和角色表现。每个启用的插件独立运行并使用自己的 Python 依赖；插件仍具有当前用户的文件与网络权限，只安装可信来源。

## 安装与设置

打开“设置 → 插件”，从市场安装，或在“更多”中从 ZIP、文件夹安装。安装后启用并应用设置。可选插件不会因为源码存在于 `plugins/optional/` 就在普通启动时自动安装。

选择插件后打开其设置。编辑字段后点“完成”，再在设置页应用才会提交；取消或关闭插件窗口恢复该插件本次打开时的可编辑值，其他草稿保留。测试连接、下载和数据增删等动作点击后即执行，取消窗口不撤销这些动作。

配置保存与应用分别反馈。应用失败不等于保存失败，需要重新加载时按页面提示操作。启停、重载和卸载只影响目标插件与依赖它的必要插件，不重启整个应用。

列表和详情用图标与文字显示运行状态：勾选表示已就绪，暂停表示已停用，加载图标表示正在启动或处理任务，警告与错误图标表示需要处理。正常状态使用低强调样式，异常显示具体状态和错误详情。启用开关是待保存的设置，运行状态以实际结果为准。

卸载移除所选用户插件的代码，保留配置和数据。同 ID 还有其他副本时，共用的 Python 依赖和启停选择也会保留。内置插件不能卸载，其中可替代的默认能力可以停用。

## 更新与修复

开启“关于 → 自动检测更新”后，每次应用启动检查已安装用户插件的更新，包含已停用插件。发现可安装的兼容稳定版本后，会话连续空闲 3 秒时由角色合并提醒；同一插件的同一目标版本每天成功提醒一次。关闭自动检测后仍可手动刷新。内置插件随应用更新，市场未收录的本地插件无法自动检查。

已安装列表显示可更新数量，插件卡片和详情中的“查看更新”按钮打开市场详情。更新入口与运行状态分开显示。进入插件页、从其他设置页返回，或查看插件页时窗口重新获得焦点，都会检查最新目录。有缓存时先显示缓存，联网更新期间可以继续浏览；失败时保留缓存，并提供错误详情和重试入口。也可以在“更多”中手动刷新。

市场、ZIP 和文件夹均支持更新和重新安装，保留配置、模型、数据和启停选择。本地包与已安装插件同 ID 时直接更新；存在重复副本时，按列表显示的版本和目录卸载多余副本，再重试。更新先准备新代码和依赖，再短暂停止相关插件并切换版本；文件切换失败恢复旧版，切换中断则在下次启动前恢复。安装完成但启动失败时保留新版本，并显示启动原因，可以继续修配置或重新安装。更新成功但旧文件清理失败时保留新版和错误详情，下次启动继续清理。主程序升级保留已安装的可选插件，插件版本由用户通过市场或本地安装包更新。

插件缺失或依赖损坏时，在市场选择安装或重新安装修复，不需要删除用户数据。更新恢复失败的插件仍会留在列表中；解除文件占用等故障后，重新安装会先恢复旧事务，再应用新包，无需重启应用。更新记录本身损坏时，重新安装会保留坏记录和旧文件，再继续修复。

准备依赖期间可以继续保存其他插件的设置，也可以停用或卸载正在更新的插件。切换版本时采用最新的启停选择；已卸载的插件不会被这次更新重新装回。

## 下载插件资源

市场与主程序更新使用“插件 → 更多 → 下载源”中的顺序。插件自己的模型和整合包由该插件设置管理，二者分开配置。

Python 依赖默认使用阿里云 PyPI。默认源的 wheel 或元数据返回 404 时，刷新索引后依次尝试华为云、官方 PyPI；显式指定的源不自动切换。需要自行选源时，可在启动前设置 `UV_DEFAULT_INDEX`。普通启动不会联网补装 Python 依赖。

资源的安装、进度、取消和重试在所属插件中进行。“关于 → 组件”汇总已启用插件的资源并链接到设置；资源已安装不代表外部服务正在运行。

| 能力 | 使用约定 |
|---|---|
| SakuraTTS | 内置语音引擎；支持本地整合包与在线安装，安装检查成功才替换原环境，失败或取消保留原安装 |
| GPT-SoVITS、Genie | 市场安装后配置本地资源或已有 HTTP 服务；引擎环境独立于 Sakura |
| SenseVoice | 安装识别模型与 VAD，再配置麦克风和识别语言 |
| Mem0 | 准备本地向量模型；自动整理另需选择模型，已有记忆可手工管理 |
| Spine、手机网页端、浏览器 | 按需安装，资源格式和连接方法见所安装插件说明 |

SenseVoice 模型、GPT-SoVITS 模型默认使用 ModelScope。资源镜像失败后尝试下一来源；已有来源配置优先，镜像不改变资源版本。GPT-SoVITS 的 macOS 安装源可通过 `GPT_SOVITS_REPO`、`GPT_SOVITS_MINIFORGE_URL` 等覆盖，详见[安装脚本](../../plugins/optional/sakura_gpt_sovits/install_gpt_sovits_macos.sh)。Intel Mac 缺少上游兼容依赖时可以连接已有服务，更换镜像不能解决架构不支持。

## 联网工具与 MCP

内置联网工具提供百度、Bing 和 Tavily 搜索，默认百度；Tavily 需 API Key。搜索返回标题、链接和摘要，读取返回正文，过长内容截断。它不能读取登录后的内容或需要浏览器执行脚本的页面，浏览器操作需独立插件。可在插件设置测试搜索，停用后其他能力仍按各自配置联网。

MCP 基础组件为服务插件提供连接能力，没有独立服务器管理页；单独启用它不会新增聊天工具。需要具体功能时安装对应服务插件并完成配置。

## 排查

先区分安装依赖失败、插件启动失败与某次任务失败。在插件页查看具体原因，再到[运行日志](diagnostics.md)按插件和时间定位。宿主记录安装、依赖、加载过程，插件业务记录位于插件日志。

开发插件见 [Plugin API v4](../development/plugin-sdk.md)。
