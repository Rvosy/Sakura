# 角色、工坊与桌面外观

角色包保存人设、表现资源、主题和语音资源。本机当前角色、启用哪个语音引擎等使用偏好留在本机，分享角色不会带走这些选择。

## 导入与编辑

在“角色与布局”导入 `.char` 并选择角色。完整角色使用 `.char`，单独表现资源使用 `.visual`，语音资源使用 `.voice`。旧版角色包仍可导入，已有资源保留。

从“修改角色”打开应用内角色工坊，可以新建、编辑、预览和导出。草稿与发布到角色分开保存；发布失败保留草稿并指出具体资源问题。新形态导入不会替换已有默认选择，未安装插件拥有的资源也应保留，安装对应插件后再使用。

删除角色包前会确认。角色从本机移除后，聊天记录与记忆保留；重新导入相同 ID 的角色可继续使用。删除当前角色后选择其他角色，删除最后一个后进入待配置状态。

源码运行可以从 `base_characters/`（兼容 `base_charaters/`）导入种子角色。已有 ID 不重复导入，用户已删除的种子角色不会随重启恢复；需要时手动导入。

## 显示方式与布局

每个角色可有多套显示形态，形态由对应表现插件提供。使用立绘需启用立绘插件；Spine 等动态表现需另装插件和资源。选择角色或显示方式后，按设置页提示应用。

“角色与布局”调整角色、气泡、输入栏的位置与尺寸，“外观”调整字体、颜色及背景效果。滑块即时预览，保存后写入当前配置；取消或预览失败恢复可用状态。长回复在气泡内滚动，外框不随文字不断长高。

切换角色先停止旧角色正在执行的任务，保留可复用的引擎；旧异步结果不能覆盖新角色的界面和数据。

## 鼠标与多屏

拖动角色或气泡空白处可移动桌宠；文字、输入框、按钮和滚动条保留正常交互，右键角色打开菜单。透明区域交给下方窗口；Linux 的具体限制见[安装指南](setup.md#linux)。

位置以角色底部中心为基准。首次显示放入可用工作区，之后尊重用户位置，包括多屏负坐标。缩放时保持位置稳定，调整结束后更新鼠标响应区域。

## 平台效果

Windows 支持纯色和条件允许时的实时高斯模糊；macOS 支持原生材质及系统提供的 Liquid Glass；Linux 的 X11 会话支持纯色和高斯模糊，输入栏停下后采样桌面，Wayland 只用纯色。液态玻璃在 Linux 上不可用。不支持的选项置灰，其他平台保存的偏好保留。

原生效果不可用时使用纯色并提供日志原因。鼠标位置不对或窗口跳动时，记录系统、屏幕排列、缩放比例与操作顺序，查看[运行日志](diagnostics.md)。

角色格式和插件接入见[角色开发约定](../development/characters.md)。
