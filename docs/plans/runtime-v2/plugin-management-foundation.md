# 插件管理页与通用设置页方向

插件页需要容纳逐步增加的功能扩展、能力提供方和基础组件。独立原型已提交为 `75d3fa78`，正式页面已接入插件清单、
分组筛选、设置窗口和原有保存链路。当前行为以 [Plugin Runtime v4](../../specs/runtime-v2/sakura-plugin-runtime-v4.md) 为准。

本次改造以外观为范围。正式实现保留原有设置字段、默认值、校验、保存语义和业务调用链，不把 demo 中的模拟行为当作新增功能要求。
组件下载集中到各自插件设置窗口；“关于 → 组件”汇总已启用插件的安装状态和下载进度，并提供定位到资源的跳转。
其他设置、领域功能及下载任务逻辑维持现状。

## 页面组织

插件使用两个独立的展示维度：角色决定列表分组，领域作为标签和筛选条件。安装来源由安装记录决定，与作者名称分开呈现。

| 维度 | 展示选项 | 用途 |
|---|---|---|
| 角色 | 功能扩展、能力提供方、系统组件 | 分组和快速切换 |
| 领域 | 模型、语音、记忆、工具、连接、其他 | 标签和组合筛选 |
| 来源 | 内置、用户安装 | 说明安装来源，不表示运行权限差异 |
| 状态 | 有问题、已禁用 | 查找故障或停用的插件 |

保留“插件列表＋详情”的结构。列表中每个插件使用独立卡片，通过边框、底色和间距区分条目与选中状态。
选中卡片不显示左侧色带。下拉列表采用与主程序一致的可主题化弹层，避免原生展开列表脱离 Sakura 的样式。
卡片展示名称、简介、领域、来源和运行状态，启用开关集中在详情中。
系统组件默认收起，入口固定在列表底部并显示数量、异常数；搜索或筛选命中时展开。详情中的依赖项可以跳转到对应插件，
跳转时清除阻挡目标的筛选条件。筛选结果为空时，详情同步清空。

详情以插件身份和概览为中心。名称与标签放在左侧，运行状态放在右侧的“插件设置”按钮下方，用轻量标记表示；
未声明设置页时，右侧只展示运行状态。错误或待处理原因显示在介绍之后。
启用状态另有明确文字和开关。配置保存成功不等于插件运行正常，开关也不承担模型加载、下载或故障状态的表达。

基础动效参考正式设置页：沿用 `cubic-bezier(0.22, 0.61, 0.36, 1)` 和 120/180/260ms 的交互时长，
应用于按钮反馈、开关、详情切换、菜单及弹窗。系统启用减少动态效果时关闭这些动画；表单刷新不反复播放详情入场。

## 通用插件设置页

“插件设置”使用详情标题右侧的紧凑按钮，在统一窗口容器中展示该插件已有的设置贡献。窗口保留插件名称，支持分组和高级折叠区；
长内容在窗口内部滚动，操作按钮始终可达。关闭后保留背后的选中插件、筛选和列表位置。未声明设置的插件不显示入口。

窗口内容以现有 Settings Contribution 为依据。不能按插件 ID 或领域猜测设置项目，也不能为了填充版面设计不存在的设置。
字段名称、类型、默认值、范围、必填条件、只读状态、条件禁用及已有动作均保持现状。模型选择、角色音色、参考音频、记忆内容管理等领域功能沿用现有页面与调用链。

原型已按现有声明收敛设置样例：

| 插件 | 普通设置字段依据 |
|---|---|
| GPT-SoVITS | `plugins/builtin/sakura_gpt_sovits/plugin.py` 的 `runtime` 声明，共 8 项 |
| Genie | `plugins/builtin/sakura_genie/plugin.py` 的 `runtime` 声明，共 3 项 |
| Sakura Mobile | `plugins/builtin/sakura_mobile/plugin.py` 的设置声明，含只读状态和刷新动作 |
| Mem0 | `plugins/builtin/sakura_mem0/plugin.py` 的 `settings_descriptor()`，运行状态与自动整理间隔 |
| Playwright Browser | `plugins/optional/playwright_browser/plugin.py` 的设置声明，仅无头模式 |

两款语音插件不增加声音模型、输出语言、语速、参考音频选择、分段或流式开关。GPT-SoVITS 原有的“远程参考音频目录”是已有服务的路径映射字段，继续保留。
Mobile 不增加允许发送文件开关；Mem0 不增加召回条数、范围、阈值或去重选项。
模型规划示例、生态样例和模拟安装的 Notebook Companion 只用于检验列表布局，不提供杜撰的设置页。

原型中的 `settingsPage: { title, description, sections }` 只是演示数据的组织方式，不是新增的 SDK 契约。
普通字段沿用源码声明，例如：

```javascript
{
  key: "timeoutSeconds",
  label: "合成超时",
  type: "integer",
  default: 60,
  minimum: 1,
  maximum: 300,
  step: 1,
  placement: "advanced"
}
```

渲染器复用同一表单路径；条件字段按原有 `enabledWhen` 保持可见，在条件不满足时禁用。
模拟保存、取消与动作仅方便查看页面效果。正式窗口的“完成”保留草稿，“取消”恢复本插件打开窗口时的字段；
底栏“应用”或“保存并关闭”继续统一提交。语音区块直接复用 Voice controller 控件，普通插件沿用原设置控制器。
资源和 Collection 动作仍按原调用链执行，不随窗口取消回滚。

### 语音组件下载入口迁移

正式页面已将“关于 → 组件”中的 GPT-SoVITS 模型/运行整合包和 Genie 整合包下载，迁入各自插件设置窗口的
“本地运行组件”分组；关于页只提供组件总览与跳转，语音领域页不再重复提供这两项下载入口。
原型中 Genie 展示已安装状态，GPT-SoVITS 演示下载、取消、重试与安装完成；这些操作只推进页面内的模拟进度。

沿用现有 Resource 字段、load callback 与 Action。Genie 使用固定整合包；GPT-SoVITS 继续按平台和显卡规则显示
一个推荐包。自定义服务显示无需安装，没有兼容包时显示不支持。下载线程、取消、续传、校验、安装及配置更新仍由
对应插件实例管理，通用设置窗口负责展示与调用，不按插件 ID 编写下载表单。

下载入口迁移复用现有动作调用和资源状态读取，不改下载任务的生命周期或配置更新规则。
原型只模拟进度、取消和重试：模拟任务可在窗口关闭后继续，资源适用状态根据已保存的服务来源展示，安装结果与运行状态分别呈现。
这些演示细节不覆盖现有产品逻辑。Mem0 的本地向量模型下载也集中到插件设置；记忆内容管理保留在记忆页。
关于页聚合已启用插件的资源，显示安装与下载状态，并直接跳到对应下载设置，不直接发起资源操作。
[语音 Spec](../../specs/runtime-v2/WP-4-05-tts-playback-audio-device-gate.md) 与插件 surface 测试已同步为 `surface=plugin`，
保留原 `aboutBundle` section ID、资源声明和动作。

## 基础设施边界

正式展示元数据使用可选的 `presentation.kind`、`presentation.category` 和 `presentation.icon`。它们只影响展示，不参与启动顺序、
依赖解析、服务选择、权限或领域业务判断。已有插件缺少展示元数据时仍应可见、可管理，不因新增分类而失去加载资格。

系统组件分类只用于展示。依赖解析、启停资格、停用影响及运行状态继续来自现有实现；原型中的依赖提示不定义新的级联停用规则。
不要把展示分类反推为运行依赖，也不要从 ID 前缀猜分类。

TTS Hub 可以作为语音系统组件呈现。模型运行时、Local LLM、Remote API 在本原型中是明确标注的规划示例。
Model Runtime Contract 属于契约文档，只有实现该契约的组件才作为插件条目展示。

不增加插件市场、评分、推荐、依赖图可视化或新的后台恢复机制。

用户后续确认将功能图标统一为 Lucide，并优化发送按钮与记忆页动效。图标使用随包资源；记忆准备动画、
发送和常用图标反馈采用 Lucide Animated 的原生适配，保持既有操作语义。详见 [图标与动效说明](../../../desktop/frontend/assets/lucide/README.md)。
[Plugin Runtime v4](../../specs/runtime-v2/sakura-plugin-runtime-v4.md) 的逐插件进程与可替换能力边界继续有效。

## 实施与验证

当前阶段已提供 5、9、30 个插件的场景、组合筛选、折叠分组、状态展示、依赖跳转、停用影响提示和通用设置窗口。
全部使用演示数据，设置只保存在页面内存中；安装、卸载、启停和保存均不调用真实后端，不读取用户数据。

本次验证重点是设置字段与原有声明一致，以及调整后的外观和交互：

- 运行状态位于详情标题右侧，设置按钮下方；选中卡片没有左侧色带。
- GPT-SoVITS、Genie、Mobile、Mem0、Playwright 的设置无额外虚构项。
- 已有服务字段始终可见，切换来源后按原有条件启用或禁用；可选字符串允许留空。
- 只读状态不作为配置保存；端口和超时按声明范围校验；高级区中的错误字段可被定位。
- 模型规划与安装样例没有虚构设置入口；弹窗内的下拉、滚动与退出动效正常。
- 两项语音整合包在各自设置窗口展示，下载、取消、重试仅改变演示进度。

正式实现另行验证展示分类的兼容回退和桥接校验、筛选行为、语音草稿保留与取消、整合包 surface 迁移以及插件管理纵向链。
浏览器检查加载正式 settings 页面并注入隔离 IPC，验证弹窗、主题下拉、资源动作刷新和底栏提交；它不能替代真实 WebView、
设备和整合包下载验收。原型保留在独立目录，不加载于正式设置窗口；原型提交与产品实现分开，方便独立回退。
