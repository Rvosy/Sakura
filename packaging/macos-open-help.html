Sakura 无法在 macOS 上打开？

如果系统提示无法验证开发者，请按照 Apple 官方流程继续。该流程只为这份应用 保存本机例外，不会关闭 macOS 的全局安全检查。

先核对下载来源。 只有在 Sakura 来自 官方 GitHub Releases 且文件符合发布说明时才继续。来源不明时请删除文件，不要绕过系统提示。

Apple 官方处理步骤

  1. 先尝试打开一次 Sakura

    关闭系统拦截提示。尝试后，“仍要打开”按钮会保留约一小时。

  2. 打开“系统设置”

    选择“隐私与安全性”，然后向下找到“安全性”。

  3. 点击“仍要打开”

    先确认页面显示的应用是 Sakura，再继续。

  4. 完成身份验证

    输入 Mac 登录密码并再次确认。之后该应用会作为例外保存。

受组织管理的 Mac 可能需要管理员协助。如果页面中没有“仍要打开”，请重新尝试打开 Sakura， 然后在一小时内返回“隐私与安全性”。

查看 Apple 官方说明 核对 Sakura 官方 Release
本文不会要求关闭 Gatekeeper、运行未知终端命令或修改系统的全局安全策略。
