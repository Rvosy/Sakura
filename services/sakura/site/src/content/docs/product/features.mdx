Sakura 在桌面显示角色，并结合人设、聊天记录和已启用插件提供的上下文生成回复。

| 功能 | 使用方式 |
|---|---|
| 角色与外观 | 导入 `.char` 角色包，在角色工坊编辑人设、表现资源和主题 |
| 聊天与图片 | 输入文字或附加图片，选择支持对应输入的模型 |
| 屏幕感知 | 开启后按设定周期观察屏幕，由模型决定是否主动搭话 |
| 网页搜索 | 自带联网工具插件，搜索公开网页并读取内容 |
| 语音与记忆 | 安装并配置 GPT-SoVITS、Genie、Mem0 等可选插件 |
| 扩展能力 | 从插件市场安装浏览器、语音输入、手机网页端等插件 |

## 工具与权限

聊天中由用户发起的工具调用通过参数检查后会直接执行。插件以当前用户权限访问文件和网络，应检查来源及功能后再安装。
主动屏幕观察使用只读、低风险工具；需要修改文件或执行其他会改变外部状态的操作时，先向用户提出建议。

网页搜索由联网工具插件提供，支持百度、Bing 和 Tavily，默认使用百度。MCP 基础组件供服务插件连接服务器，具体功能和配置由服务插件提供。
