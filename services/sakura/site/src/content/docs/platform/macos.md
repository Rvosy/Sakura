title: macOS 指南
description: macOS 安装、屏幕权限、窗口与语音配置入口。
---

从 [Releases](https://github.com/Rvosy/Sakura/releases) 下载与处理器架构匹配的完整包。应用包含 Tauri 桌面程序和 Python Runtime。

首次打开被 Gatekeeper 阻止时，先尝试启动，再到“系统设置 → 隐私与安全性”使用“仍要打开”。截图与主动屏幕感知需要屏幕录制权限，授权后重新启动 Sakura。

详细安装步骤、源码运行、架构与证书排查，以及语音服务配置见 [macOS 使用指南](https://github.com/Rvosy/Sakura/blob/main/docs/userdocs/MACOS_SETUP.md)。
