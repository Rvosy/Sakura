title: 插件 SDK
description: Plugin API v4 开发指南与示例入口。
---

Sakura 使用 Plugin API v4。每个启用插件在独立进程和依赖目录中运行，通过 Service、Event、Effect、Config 和 Data 接入宿主。插件以当前用户权限访问文件和网络，只安装可信来源。

从 [SDK 开发指南](https://github.com/Rvosy/Sakura/blob/main/docs/development/plugin-sdk.md)中的最小插件开始，按需要添加工具、上下文、设置或表现资源。清单、接口、示例和兼容规则见该指南。

- [插件能力接入](https://github.com/Rvosy/Sakura/blob/main/docs/development/plugin-recipes.md)
- [插件安装与使用](https://github.com/Rvosy/Sakura/blob/main/docs/guide/plugins.md)
