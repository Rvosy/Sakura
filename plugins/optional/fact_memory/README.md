# 便签记忆

把希望角色记住的事实写成便签，聊天时按关键词找到相关内容。便签由你增删和修改，保存在插件自己的 SQLite 数据库中，
各角色分别保存。插件不需要 embedding、额外模型或资源下载，也不会读取、整理或修改 Mem0 的数据库。

这是可选插件 `fact_memory`，版本 `0.1.1`，使用 Plugin API v4 和 Context schema 2。
安装、启用及管理都沿用插件自己的设置入口，日常聊天继续使用默认 Assistant 和原有模型配置。

## 安装与填写

已安装 `0.1.0` 时，先在“设置 → 插件”选择“便签记忆”，点击“卸载插件”，在确认框点击“卸载”。
现有卸载入口保留插件设置和便签数据；随后按下面的步骤安装 `0.1.1` 并重新启用，原启用状态不会保留。
`0.1.1` 修正显式搜索漏查正文的问题，数据库格式和已有便签不变。

1. 从“设置 → 插件 → 安装插件… → 从 ZIP 安装…”选择 `fact_memory-0.1.1.sakplugin.zip`。
   开发时也可使用“从文件夹安装…”，选择本目录 `plugins/optional/fact_memory`。
2. 在插件列表选择“便签记忆”，启用插件并应用设置，确认插件正常运行。
3. 打开它的“插件设置”，点击“新增”。填写“内容”和可选“关键词”，点击“创建”。
4. 回到聊天窗口，发送包含关键词的问题。新保存的便签会参与下一轮上下文匹配。

例如，内容填写“验收项目交付时间是周五下午三点”，关键词填写“验收项目”，然后询问“验收项目什么时候交付？”

内容必填，最多 1000 字符；关键词最多 200 字符，多个关键词用逗号分隔。也支持中文逗号、顿号、分号或换行。
列表可以搜索内容或关键词，选中已有条目后可以更新或删除。Collection 的创建、更新和删除直接保存，
不需要再按主设置窗口的“应用”。已开始的回复继续使用本轮采集的内容。

## 怎样召回

自动补充上下文时，有关键词的便签在输入包含任意一个关键词时命中，匹配忽略大小写。没有关键词的便签使用轻量文字匹配：
中文按相邻两字、英文按完整单词寻找交集。关键词命中排在前面，其次比较命中数、更新时间和稳定 ID。
想得到容易判断的结果，建议给重要便签填写具体关键词。

每次最多选 5 条，便签正文合计不超过 2000 字符；整条装不下就跳过，继续尝试后面的条目，不截断正文。
用于标识便签的标题和编号不计入正文额度。没有相关便签时不添加内容，默认对话仍会按自己的模型窗口预算处理可选上下文。

只读工具 `fact_memory_search` 按查询文字在内容或关键词中直接查找，忽略大小写，并去除查询两端的空白。
填写过关键词的便签也能按正文查询：上面的示例用“交付时间”即可查到。工具按更新时间从新到旧返回，
相同时间按 ID 稳定排序，同样遵守 5 条和 2000 字符的限额。它不做模糊或语义搜索。

模型按需调用工具，是否查询及怎样回答由现有 Assistant 决定。插件没有自动提取、改写或删除便签的功能，聊天本身不会新建便签。

## 修改、重启和停用

把示例便签改成“验收项目交付时间是周六下午三点”，点击“更新”，退出并重新启动 Sakura。
再次打开插件设置，内容应保持修改后的值；下一轮匹配应提供周六的便签。

删除条目无法恢复，插件的后续查询和上下文不再提供它。停用插件后，后续对话不再使用它贡献的 Context 或搜索工具，
保存的便签仍在，重新启用可以继续使用。切换角色后只能查看、编辑和召回该角色的便签。

聊天历史或其他记忆插件可能仍保存旧事实。删除或停用后，模型仍提到旧内容不一定表示此插件还在贡献它。
验收时查看当轮 Prompt Trace 中来自 `fact_memory` 的 Context；同时检查历史消息和其他来源。
需要只验证便签记忆时，可由用户暂时停用 Mem0；两者的数据不会自动互相转换。

## 打包与验证

在仓库根目录运行，输出路径必须尚不存在：

```powershell
runtime\python.exe tools\release\package_optional_plugin.py --source plugins\optional\fact_memory --output dist\fact_memory-0.1.1.sakplugin.zip
```

macOS/Linux 使用 `runtime/bin/python`。数据库由 `context.data_path("facts.sqlite3")` 创建在插件私有数据目录中。
安装包只含插件代码，不打包用户便签。

真实 Core、插件进程和模型请求的验收入口是 `tests/integration/test_fact_memory_core_protocol.py`。
日常试用可通过 [`scripts/start-existing-data.bat`](../../../scripts/start-existing-data.bat) 使用已有角色和配置，
再由用户安装、启用本插件；开发者不为验收自动改写日常便签或插件开关。
完整边界见[便签记忆规范](../../../docs/specs/runtime-v2/fact-memory.md)和[生态验收指南](../../../docs/devdocs/PLUGIN_ECOSYSTEM_ACCEPTANCE.md)。
