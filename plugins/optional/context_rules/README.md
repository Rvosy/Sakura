# 对话规则

在插件设置中填写行为规则和参考资料，让当前角色按这些规则进行对话。默认规则让回复更简短。
插件使用公开的 Context 和设置接口，不修改角色文件或原角色人设。

此初版需要运行本工作树构建的 Sakura。旧版本尚不支持行为规则，插件会启动失败并报告
`CONTEXT_RULES_HOST_UNSUPPORTED`，不会把规则悄悄当作参考资料发送。

Context 仍是开发阶段接口。[开放插件生态计划](../../../docs/plans/runtime-v2/open-plugin-ecosystem.md) 的 M1 将移除用途分类，
把本示例合并为一个上下文输入框并保留已有文本。这些调整尚未实施，以下说明对应当前初版。

## 安装与使用

1. 打开 Sakura 的“设置 → 插件 → 安装插件… → 从文件夹安装…”，选择本目录
   `plugins/optional/context_rules`。收到 `.sakplugin.zip` 包时，使用“从 ZIP 安装…”。
2. 在插件列表中选择“对话规则”，启用插件并确认它已正常运行。
3. 打开“插件设置”，编辑“行为规则”和“参考资料”。点击“完成”后，再点击设置窗口的“应用”。
4. 回到聊天窗口发送一条消息。保存的修改从下一轮对话生效，当前正在生成的回复继续使用本轮已采集的规则。

两个字段均可留空，每个字段最多 4096 个字符。“行为规则”用于说明如何回应；“参考资料”用于放入课文、
背景事实等内容。参考资料按资料语义送入模型，与行为规则分开呈现。当前设置界面使用普通文本输入框，
规则可以用连续句子填写。

例如，日语练习时把“行为规则”改为：

> 主要用日语和我交流。发现我的日语有明显语法错误时，先给出自然的改写，再继续对话。
> 我要求中文解释时，用中文说明原因。

“参考资料”可以填：

> 我目前正在学习日语过去时，今天练习介绍周末做过的事情。

需要简洁表达时，把“行为规则”改为：

> 先直接回答我的问题。通常用两到三句说明，不重复问题。遇到需要操作的任务时列出具体步骤。
> 我要求详细解释时再展开。

规则通过提示词影响模型，执行程度取决于所用模型。已填写的行为规则必须完整进入本轮上下文；
加载失败或上下文容量不足时，本轮会报错，避免在规则缺失时继续生成。参考资料仍可能因预算不足被裁剪。

停用插件后，下一轮不再添加这些规则与资料；已有聊天记录和已保存的插件设置会保留。
本插件没有改变长期记忆的学习流程。

## 打包

在仓库根目录运行以下 PowerShell 命令，输出路径必须尚不存在：

```powershell
runtime\python.exe tools\release\package_optional_plugin.py --source plugins\optional\context_rules --output dist\context_rules-0.1.0.sakplugin.zip
```

macOS/Linux 使用 `runtime/bin/python`，路径分隔符改为 `/`。插件没有额外 Python 依赖，不需要下载模型或资源。

开发其他行为插件时，可以参考 `plugin.py` 的能力检查、`scope: turn` 登记和
`kind: instruction` 返回值。插件停用时，SDK 和宿主负责撤销登记；无需修改 Core 来登记业务类别。
