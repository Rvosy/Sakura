# SakuraTTS

离线角色语音插件。空闲后由 SakuraTTS 释放推理进程；对话开始时可利用等待大模型回复的时间提前加载模型。

从[魔搭](https://modelscope.cn/models/SuzushimaArisu/SakuraTTS)下载对应平台的整合包。安装插件后，在插件设置中选择“导入整合包”，导入与本机平台匹配、包含准备组件的完整包。Windows 使用 x64 统一包，macOS 使用 Apple silicon 包。角色的 GPT、SoVITS 权重和参考音频沿用角色资源，在语音页选择 SakuraTTS。

“自动”在 Windows 优先检查 NVIDIA CUDA，检查失败则使用 CPU；macOS 使用 MLX。手动选择的后端失败时会报告错误。“AMD / Intel 显卡”使用 DirectML，需要手动选择且整合包须包含对应后端。设置页面和应用启动不会加载模型。

选择“NVIDIA（英伟达）”后显示“推理精度”，默认 FP16 标准，可切换到 FP32 全精度、FP16 低显存或 FP16 极低显存。低显存档通过分阶段加载模型减少占用，可能增加合成耗时。应用设置后，下次合成使用新档位；首次使用 FP16 会转换模型，三个 FP16 档共用缓存。此功能需要支持 CUDA FP16 自动转换的新版整合包。“自动”继续使用引擎默认精度，不应用隐藏的 NVIDIA 档位。

整合包导入成功后无需重启。在语音页为当前角色启用语音并选择 SakuraTTS，首次合成会自动加载模型。“未加载”和空闲后的“已卸载”均不表示插件启动失败。

再次导入即可更新整合包。新包检查通过后才切换，失败或取消保留原有安装；模型缓存、角色资源和插件设置保留在版本目录之外。当前尚未提供在线下载、检查更新和一键回退。

运行日志的“TTS”栏显示服务启动、提前加载、排队、合成阶段耗时、音频时长、参考缓存状态和错误原因。阶段数据由支持诊断响应头的引擎提供，旧包仍显示请求总耗时。完整引擎日志保存在插件数据目录的 `runtime-data/server.log`，错误详情保存在 `last-error.log`。支持范围和整合包构建方法见 [SakuraTTS](https://github.com/Rvosy/SakuraTTS)。
