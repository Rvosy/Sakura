# SakuraTTS

内置离线角色语音插件，随 Sakura 安装并默认启用，可在插件页停用。空闲后由 SakuraTTS 释放推理进程；对话开始时可利用等待大模型回复的时间提前加载模型。

模块职责、安装切换、任务生命周期及与 TTS Hub 的协作见 [SakuraTTS 规格](../../../docs/specs/sakuratts.md)。

在插件设置中点击“下载并安装”，从魔搭下载最新预览版并自动安装。也可从[魔搭](https://modelscope.cn/models/SuzushimaArisu/SakuraTTS)手动下载，在插件设置中选择“导入整合包”。Windows 使用 x64 统一包，macOS 使用 Apple silicon 包。角色的 GPT、SoVITS 权重和参考音频沿用角色资源，在语音页选择 SakuraTTS。

“自动”在 Windows 每次启动服务时优先检查 NVIDIA CUDA；设备不可用或驱动不兼容时使用 CPU，运行状态显示原因，休眠后仍可查看。路径、依赖或编译错误会提示具体原因和日志位置。连续合成复用服务，停止后再次启动会重新检查。macOS 使用 MLX。手动选择的后端失败时会报告错误。“AMD / Intel 显卡”使用 DirectML，需要手动选择且整合包须包含对应后端。设置页面和应用启动不会加载模型。本机运行检查、模型加载和合成等待实际结果，取消或停止服务时回收进程。

选择“NVIDIA（英伟达）”后显示“推理模式”，默认 FP16 标准，可切换到 FP32 全精度、FP16 低显存或 FP16 极低显存。低显存档通过分阶段加载模型减少占用，可能增加合成耗时。应用设置后，下次合成使用新档位；首次使用 FP16 会转换模型，三个 FP16 档共用缓存。此功能需要支持 CUDA FP16 自动转换的新版整合包。“自动”继续使用引擎默认精度，不应用隐藏的 NVIDIA 档位。

整合包导入成功后无需重启。在语音页为当前角色启用语音并选择 SakuraTTS，首次合成会自动加载模型。“未加载”和空闲后的“已休眠”均不表示插件启动失败。

整合包和引擎缓存默认放在用户数据根下的 `tts/sakura`。Windows CUDA 环境遇到中文默认目录时，会自动迁到同盘的 ASCII 路径，保留配置、角色资源和缓存。用户指定的外部整合包目录继续沿用；若 CUDA 无法使用该路径，可在“运行环境目录”填写 `D:\SakuraTTS` 等短路径，再点击“迁移运行环境”。文件缺失时可重新导入，或点击“重新下载并安装”。具体位置、迁移恢复与便携版移动约定见[安装与切换](../../../docs/specs/sakuratts.md#整合包安装与切换)。

默认在插件启动时检查整合包更新。已安装环境有可用版本时，等待当前角色空闲后，通过对话模型 API 生成角色口吻的提醒；同一版本当天成功提醒后不再重复。可关闭“启动时检查整合包更新”。自动检查和提醒不会下载或安装。

点击“下载并安装”后连续完成下载、解压和运行检查，下载期间仍可使用原有环境；完整下载可在取消安装或重启后通过“安装已下载整合包”继续安装，未完成的下载不支持断点续传。也可再次导入本地包更新。新包检查通过后才切换，失败或取消保留原有安装；模型缓存、角色资源和插件设置保留在版本目录之外。取消完成后显示当前安装状态，取消记录保留在运行日志中。尚未提供一键回退。

运行日志的“TTS”栏显示服务启动、提前加载、排队、合成阶段耗时、音频时长、参考缓存状态和错误详情。阶段数据由支持诊断响应头的引擎提供，旧包仍显示请求总耗时。完整引擎输出和运行检查日志的位置见[失败与诊断](../../../docs/specs/sakuratts.md#失败与诊断)。支持范围和整合包构建方法见 [SakuraTTS](https://github.com/Rvosy/SakuraTTS)。
